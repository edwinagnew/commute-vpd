reports/<type>/YYYY-MM-DD_<type>_<topic>.md, one folder per type (plans, analyses, reviews, decisions, predictions, digests). The analysis reports are the record; this log is the explanation.
Code
src/commute/ holds everything shared between experiments; cluster/ the Slurm scripts (README.md there); theory/ the notes.
