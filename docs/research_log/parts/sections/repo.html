Where things live

Read first
README.md (state of play), GOALS.md (the question, user-owned), decisions.md (working choices with dates and reasons), experiments/TRIED.md (every experiment, with E-codes, and why we moved on).
Experiments
experiments/<name>/: run.py, plot.py, results/ with predictions.json and the scored JSON, figures/. Over 1 MB goes to the gitignored results/large/.
Reports
reports/YYYY-MM-DD_<plan|prediction|analysis|review|decision>_<topic>.md. The analysis reports are the record; this log is the explanation.
Notebooks
notebooks/, rewritten 2026-10-20 for E8, E9, E11 with corrected values.
Shared code
src/commute/: component_training.py, split.py, faithfulness.py (Pile checks), local_faith.py (route split), harness.py (shared measurement path since E8), recruit.py, kv.py, ladder.py, signatures.py (E12).
Theory
theory/: splits and obstruction formalised; component identity; reveal-versus-create literature; the project proposal.
Cluster
cluster/: one Slurm script per experiment, sync.sh, README.md. States not in git are on the cluster NFS under /mnt/nw/home/e.agnew/commute/experiments/<name>/results/large/.
Reproduce
make sync                                           # editable install
make test                                           # CPU tests
uv run python experiments/<name>/run.py --smoke     # two-step dry run
sbatch cluster/<name>.sbatch                        # scored run (account c11, partition compute)
cluster/sync.sh down                                # small results home; `large` for the states
