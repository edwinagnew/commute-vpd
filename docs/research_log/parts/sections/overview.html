Overview

Does post-training create new mechanisms, or draw from existing ones? A common assumption, resting on behavioural or activation evidence, is that pretraining builds the mechanisms and post-training only re-weights them. This project looks where post-training actually acts: in the weights.

A parameter decomposition (VPD) writes each weight matrix as a sum of rank-one subcomponents, each meant to be one piece of mechanism, plus a residual Δ, with an importance function Γ saying which pieces matter on each input. A post-training update is a change to the weights, so: does it land on the existing subcomponents, or outside them?

Definition · existing and new, without VPD

From Jain et al. 2024, Mechanistically analyzing the effects of fine-tuning on procedurally defined tasks, section 3. The original model possesses a capability f if a linear readout of some layer, trained on pretraining data, gives f on a chosen set of inputs. A fine-tune reuses f if its behaviour is g∘f for some map g and it passes a causal test: switching off or patching f breaks the behaviour, or a little pruning or reverse fine-tuning brings the old behaviour back. Otherwise the behaviour is new. Precise statement in the glossary.

Ours, not the paper's: the causal test, "new means not reuse", and a filed threshold in place of its "for all inputs". The paper defines only possession and relevance.

Measured? Not in full on any fine-tune, and not at all on Qwen. On the counting model a linear probe read the old count, but the causal test was a patch that reads 0 by construction on the new side, so that side rests on behaviour (E55). On the 67M the readouts failed (E59, E64) and a context patch gave no label (E66); the copying pair has a causal test but no readout, and its copy side is unsettled (E62); every other map is labelled only by how it was built. No VPD reading has been scored against this with its controls held, so "reveal" and "create" below are readings of the data, not verdicts.

How it is tested

Take a released decomposition, run a small fine-tune, and carry the update onto the pieces with Γ's parameters and Δ frozen (fixed gates on the 67M, not on Qwen). A rule passes if the result is still faithful to the updated model by VPD's own checks, without Δ swallowing the update.

Baselines

Baselines: can anything without a decomposition tell eliciting from new?

We compare VPD's reading with cheap readers, on fine-tunes built either to strengthen something the model already does or to teach something new. A spectrum of the weight change does not separate them. One steering vector separates them only partly, and copying neuron activations into the original model only while the two have not learned equally. VPD's re-gating share separates that pair at five seeds, but on the small model it follows how likely the original model already was to give the answer, so it has not yet shown more than the logits do. No neuron reading puts the fine-tunes built to elicit on fewer neurons on all the pairs (E63; a low-power null). Two readouts meant to label "half-known" were unreadable (E59, E64). Line 1 · Commute (Q1)

The question. Given a finished fine-tune, can we move the pieces, with Γ's parameters and Δ frozen (fixed gates on the 67M, not on Qwen), so the decomposition describes the fine-tuned model? Three tests hold together: the fine-tune's behaviour is kept; VPD's faithfulness check passes (an adversary switching pieces off does no more damage than on the original); and Δ does not absorb the update, which would pass trivially. Then the update can be written in the existing pieces.

What works: teacher training. Training the pieces to reproduce the fine-tuned model's predictions passes all three tests on every trigger fine-tune tried: three cued-answer tasks (E34) and a word cipher the model never knew (E42). One-shot splits of the finished update lose the behaviour or leave much of it in Δ (Result 2).

Where it falls short. A fine-tune with no trigger that changes text everywhere (lowercasing) is the main gap (Result 2, E39); a 10-step fine-tune is copied just at the pass line (E41).

So far. An update that teaches a cued answer can be written in the existing pieces; a broad one, not yet.

Now. The no-trigger case needs a check with power on SGD's update before it can close. An audit found teacher training's base-model control reads zero by construction; no run with the base as teacher fails the adversarial check, and a pass near 1 shows no harm and no more (E34).

Line 2 · Re-gating (Q5)

The question. After a fine-tune, frozen Γ reading the new activations switches on different pieces: re-gating. If post-training only re-weights existing mechanisms, re-gating should explain much of a fine-tune. Does it, and what does a re-gating number measure?

What we found. On toy fine-tunes that teach a fixed answer after a cue, the pieces Γ newly switches on are mostly ones the original model already uses before that answer, and putting back their outputs takes back about a fifth of the gain (E38). Where only the gating changes, the gate gain tells a behaviour the model already had from a new one (E12).

Caveats. A ranking that needs no Γ takes back as much as Γ's set (E38). The stand-in reads much the same for a fine-tune that learned nothing, a random change and a hand-made edit (E36, E46); no restore number told copy from random maps (E50).

So far. Re-gating reads whether the trained answer is one the original model already gives for that input. You decided on 2026-11-02 that elicitation means the behaviour runs through a mechanism the original model already has, so that is not yet what it reads; one cut on the model's own probability of the answer sorts the same maps. It is a candidate to score against a causal check. How much of an update it accounts for is open.

Now. On the saved 67M runs the stand-in ratio and the re-gating share put every fine-tune built to reuse above every one built to be new, by construction, on two of three families; counting the unchanged model's own masked error, the third cannot be read (E53, E54, E60). The copying-heads test left r unscored: the masks follow the copying head, but whether they open its pieces is untested (E62). A decomposition trained for 400 of 400,000 steps already labels all 21 counting fine-tunes right, so the 56-hour run was stopped (E55). The granularity limit is neither confirmed nor ruled out (E58, E60).

Line 3 · Qwen3-1.7B (Q9)

The question. Do the small model's answers carry over to a larger model with a real post-training update? Our port reproduces Qwen3-1.7B's decomposition.

What we found. The commute pass test has no teeth here, with masks from either model (E44), so since 2026-10-30 this line describes where an update lands. The re-gating share reads 0.99 or more on every state, real or random. The direct share, what changing the subcomponents alone carries with the masks held, is higher for the gold-solutions fine-tune than for random changes. Retrained at full precision, a finished one reads 0.038 above random changes of its size and a part-way one reads level, so size alone cannot be said to explain it (E61).

So far. No reading on this model tells an update that uses what is already there from one that adds something new; the direct share does not separate them on the maths fine-tune.

Now. D1 is blocked on its test (section {{n:decisions}}): it fails bad placements, but even the whole update added back closes only 0.03 to 0.14 of the KL gap, so it can pass nothing (E68).
