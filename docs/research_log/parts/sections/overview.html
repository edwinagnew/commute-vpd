Overview

Does post-training create new mechanisms, or draw from existing ones? A common assumption is that pretraining builds the mechanisms and post-training only re-weights them. The evidence for that is behavioural or activation-based. This project looks where post-training actually acts: in the weights.

A parameter decomposition (VPD) writes each weight matrix as a sum of rank-one subcomponents, each meant to be one piece of mechanism, plus a residual Δ, with an importance function Γ saying which pieces matter on each input. A post-training update is nothing but a change to the weights. So: does the update land on the existing subcomponents, or outside them?

Work in progress: what "re-weighting" means

The hypothesis is usually stated informally: post-training re-weights mechanisms pretraining built, rather than creating its own. A precise version is not written down yet. What counts as a mechanism, and what counts as re-weighting one in VPD terms (a strengthened piece, a re-switched one, a new one) is open. The grid in section {{n:techniques}} is one operationalisation, adopted for now: re-weighting as the reading where the update leaves the subcomponents as they were and Γ switches them on differently, measured by the re-switching share. Until this is fixed, "reveal" and "create" below are readings of the data, not verdicts on the hypothesis.

How it is tested

Take a released decomposition, run a small fine-tune, and try simple rules for carrying the update onto the pieces with Γ and Δ frozen. A rule passes if its output is still a faithful decomposition of the updated model by VPD's own checks, with Δ not swallowing the update.

Line 1 · Re-gating (Q5) · reset plan running

The question. After a fine-tune, the frozen Γ, reading the new model's activations, switches on different pieces than on the original model. That is re-gating. If post-training only re-weights existing mechanisms, re-gating should explain much of a fine-tune. Does it, and what does a re-gating number measure?

What we found. Our toy fine-tunes each teach the model a fixed answer after a cue. The pieces Γ newly switches on at the cue, chosen without knowing the answer, are mostly ones the original model already uses before that answer (60 to 96%, against 2 to 8% of random sets; figure above), and putting back their outputs takes back about a fifth of the gain (E38). In a stand-in where only the gating changes, the gate gain tells a behaviour the model already had from a new one, on tasks built so we know which is which (E12).

Caveats. These do not say how much of an update runs through re-gating. A ranking that needs no Γ takes back as much as Γ's set (E38). The stand-in reads much the same for a fine-tune that learned nothing (E36), a random change and a hand-made edit (E46), and no restore number told copy from random maps (E50). A new mechanism built from existing pieces under new gating reads as elicited, because VPD's unit is the single subcomponent, not the circuit.

So far. Re-gating shows what an update draws on, and whether the model already had it. How much of the update it accounts for is open.

Line 2 · Commute (Q1)

The question. Given a finished fine-tune, can we move the pieces, with Γ and Δ frozen, so the decomposition describes the fine-tuned model? Three tests must hold together: it keeps the fine-tune's behaviour; it passes VPD's faithfulness check (an adversary switching pieces off does no more damage than on the original decomposition); and Δ does not absorb the update, since putting all of it in the residual passes trivially. If all three hold, the update can be written in the existing pieces.

What works: teacher training. Train the pieces to reproduce the fine-tuned model's predictions. It passes all three tests on every trigger fine-tune tried, each teaching a fixed answer after a cue: three tasks (E34) and a word cipher the model never knew (E42). It holds under a longer adversary (E34, E47). Splitting the finished update onto the pieces in one shot loses the behaviour or leaves much of the update in Δ (Result 2).

Where it falls short. The main gap is a fine-tune with no trigger that changes text everywhere (lowercasing). The copy keeps the behaviour but, for the Adam full-matrix fine-tune, fails the faithfulness check on all 8 blocks read; the rank-8 LoRA passes (E37, E39, E49). With SGD the check cannot fail even the whole update left in Δ, so SGD is unresolved (E49). A 10-step fine-tune is copied just at the pass line (E41).

So far. An update that teaches a cued answer can be written in the existing pieces; a broad one, not yet.

Now. The no-trigger case needs a check with power on SGD's update before it can close. On the larger Qwen3-1.7B, the pass test has no teeth with masks from either model (E44), so that line now describes where the update lands.
