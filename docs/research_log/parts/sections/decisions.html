Should a fine-tune that adds a small new trigger in front of an old, unchanged circuit count as reuse?

Nothing runs until this is decided: the known-answer test (2 runs, due 2026-11-20) is held, and its predictions are filed only after your answer. M is the original model, F its fine-tune; the definition says F reuses M, for a behaviour at a declared level, to the extent that the parts F needs still compute what M's parts compute on the same inputs.

  • Measured so far. The neuron-level score saturated: 0.999 or more on every fine-tune (E208), not expected. The held-model reading separated only items new by construction (a graft 0.13, the rebuilt circuit 0.56) from old-task fine-tunes (0.98 or more). The held test would read four hand-built edits with known labels at neuron, head, MLP-layer and block level, which nothing has done.
  • The case. M copies B after a repeated A through two attention heads (its induction circuit). One reuse edit adds eight first-layer neurons that make a new cue A′ look like A; the unchanged heads then copy B. As written, the parts F needs are found by giving every part M's rule and handing F's rule back to as few parts as possible until the behaviour returns. An unchanged part is not moved by that soft intervention, so the heads never enter the set: only the new front end does, and it does not keep M's rule. The edit reads "not reused", the same as an edit writing a new answer into the same eight neurons, at every level and under every decomposition.
  • So the definition now answers "did the edited parts keep their rules?", not "how much old machinery does the new behaviour run through?".

Options (no recommendation: this is your definition question). (a) Keep it as written. The test runs as planned and mostly confirms a derivation: no coarse level separates (the three concentrated edits all read 0), and the neuron level reads the thinly spread new edit highest. The paper says reuse describes how the change was made; lost: a re-triggered old circuit reads as new, and the trained pairs are not read at a new level. (b) Count every part the behaviour runs through in F, changed or not. The unchanged heads count as kept; the planner's estimate is about 2/3 for this edit at block level and near 0 for the new edits, so the test could pass and the trained pairs would then be read at that level. It needs a new clause in the definition, in your words. Your answer (2026-11-18): if every part counts, an unneeded part is replaced by its mean over the behaviour's inputs. (The other option was its value on another input, a resample.)

What the literature does (from a review of the definition, 2026-11-18, its section 4). Circuit analysis counts every part the behaviour runs through: Geiger et al.'s sub-circuit analysis (their section 3.5.2) sets everything outside a circuit to fixed values and asks whether the circuit still produces the behaviour, which is option (b). Your replacement rule, the mean over the behaviour's inputs, is standard mean ablation (Wang et al. 2023); resampling (Chan et al. 2022) is the other standard. This is context only; the main question stays yours, with no recommendation.

Second, smaller question (you said "I don't know"; you may hand it back to the lead). When we test whether a part of F still follows M's rule, we feed the part an input and compare its output with M's version of that part. Which input do we feed it? Take the example above.

  • (A) What reaches the part in F's own run. F has learned to make the new cue A′ look like A in layer 1, so the unchanged induction heads receive "looks like A". M's copy of those heads, given the same thing, would also copy B. Same output, so the heads read as kept. This asks: did the part's own computation change?
  • (B) What reached the part when M read the same text. M never learned A′, so in M the heads received plain A′ and did nothing. In F they copy B. The outputs differ, so the heads read as not kept, even though their weights never changed. This is activation patching (Prakash et al. 2024). It asks: does the part behave the same on this text as it did in M?

Under B, any reuse that runs an old circuit on a new cue reads as new, because M never ran the circuit on that cue. Under A, it can read as reuse. Lead's recommendation: A, because only A can tell "same machinery, new cue" from "new machinery". Both are reported either way; the choice sets which one the pass rule uses. It matters only if the main answer is (b).

What the review adds here (its sections 3 and 4). The decided wording already says that, given the same input values, the part's mechanism in F gives the same output as in M. That compares two mechanisms on the same inputs, which is A, the standard meaning of "same mechanism" in causal models. B compares the values a part takes in two runs, as activation patching does, so choosing B would change decided wording. What is really open is whose input values the comparison uses: those in F's runs, those in M's runs, or both pooled. The review suggests pooled, since the standard is the values that occur on the data.

When a decomposition fits the fine-tune only approximately, should we run the test inside the refined models?

Nothing runs on this: every reading so far is exact, so the answer changes no number now. You decided today that a refinement (a declared finer model of each network, here the parts a method reads) may be approximate, with its error ε (mean KL on outputs) reported beside every reading. M is the original model, F its fine-tune, and F̃ and M̃ are their refined models.

  • The case. When ε is above zero on F, F̃ does not reproduce F exactly. The test "do these parts suffice for the behaviour?" can then be run against F itself, or against F̃. Without a choice the definition could fail to give an answer.
  • Measured so far. Nothing: all readings are exact, ε = 0, and there the two choices coincide, so no reading changes.

Options. (a) Compare inside the refined models: run the test against F̃ and compare it with M̃, so the definition gives an answer in every case. Raised by the writeup-lead, who recommends it. (b) Compare against F itself: the test uses the real fine-tune, and εF is reported beside the reading as the warning that F̃ is not F; where the approximation is poor the reading may be undefined. Lead's recommendation: (a).

What the literature does (from a review of the definition, 2026-11-18). Replacement-model circuit work tests a circuit inside the replacement model with its error nodes kept, so the model is exact (Marks et al. 2024; Ameisen et al. 2025): that is option (a). The review also shows the definition is not total without this choice: when F̃ does not keep the behaviour, no set of parts does, and under (b) no reading exists.

Raised by the writeup-lead (its small ask 1); it is part 1's definition, so the definition-lead owns it. See the "Open" paragraph in Part A of the level note.

Four repairs the definition needs before the paper states it formally

Nothing runs on this. A fresh review checked the definition against Geiger et al. and found four gaps, each needing a sentence of content that only you can add. Measured so far: every reading is an exact unit partition (neurons, heads, MLP layers or blocks, no remainder part), so no reading changes under any repair. M is the original model, F its fine-tune, F̃ and M̃ their refined models, and FK is F with M's rule on every part outside K.

  • 1. Should a decomposition read on F be allowed to use F, if the rule for doing so is fixed before any reading? The definition says the decomposition is fitted on M only. But reading VPD components on F means splitting F's weight change over them, and every useful split is computed from that change; only the do-nothing split is not, and it reads every change as new. A crosscoder, trained on both models at once, breaks the same rule. Review's repair: "F̃ is produced from M̃ and F by a rule declared before any reading (the same encoder; a named split of δW), never chosen to change the reading." Changes the guard's content; no reading. Lead: accept.
  • 2. Should everything that is not a part, the output above all, run M's mechanism in every hybrid? The soft intervention from the original model gives M's rule only to parts; the output layer and any glue keep F's. A fine-tune that changed only the unembedding then keeps its behaviour with every part on M's rule, so it needs no parts, and "the soft intervention on every part gives M" is false. Review's repair: "Every variable of N other than the input lies in some part's cell; or, the output (and any non-part variable) runs M's mechanism in every F_K." Content, a missing clause; the 67M readings already set the output to M's, so none is expected to change. Lead: accept, in the second form.
  • 3. Should every reading report how much of the parts F needs is remainder? With a remainder part the merge is exact for any encoder, so ε is always 0. A weak SAE pushes F's change into the remainder, which becomes the needed part; the reading says "new" and ε hides why. Review's repair: "report, beside ε, either the share of K that is remainder (the level note's Part B proposal) or ε of the same decomposition with its remainder removed." Changes what is reported, not the definition; no reading used a remainder. Lead: accept, with the remainder's share.
  • 4. Should M̃ and F̃ share one order of computation? A part's inputs are whatever its mechanism reads, so the two could differ. If part a reads b in F̃ and b reads a in M̃, the soft intervention on b alone makes a loop that cannot run. Every current case follows layer and position order. Review's repair: "one clause requiring a shared causal order." Content, a stated condition; no reading. Lead: accept.

Lead's recommendation: accept all four. Urgency: before the paper's formal statement of the definition.
