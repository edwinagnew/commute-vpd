Question for you · qwen-lead · new 2026-11-13

On Qwen3-1.7B the re-gating share has never been shown a change that is re-gating by construction. Should the next run give it that reference before part 3 relies on it?

Due to run: nothing on this line until you open a cell. The share asks how much of a fine-tune's effect is recovered by keeping the model's original parts and only switching them on and off; 1 means all of it.

What the numbers say.

  • Main decomposition: no information. Every fine-tune reads 0.990 to 0.9998 and random changes of the same output size 0.992 to 1.009.
  • Frozen-neuron decomposition (its parts are the MLP neurons themselves): the share varies. Fine-tunes read 0.921 to 0.995, random changes 0.81 to 1.06. Known facts minus invented facts reads 0.049 at the last save, eight times the gold-answer twin's 0.006.
  • That 0.049 is most likely size. The invented-facts update is about twice the known-facts one (weight change 4.0 against 1.9) and the share falls as a change grows. Matched in size, the gap is 0.0085, the same as two random changes give, 0.0083.
  • One possible signal. Real fine-tunes read above random changes of similar size here (gold answers 0.961 against 0.905; known facts 0.97 against 0.91), which they did not on the main decomposition. It rests on one random draw, matched in size only within a factor 1.5.

So we do not know what a high or low reading means on this decomposition, because no change that is re-gating by construction has been read.

Options. Costs on a Vast H100 NVL at $3.45 an hour, about 3 minutes a reading.

  • (a) A built re-gating change plus random changes at several sizes. Recommended. About 3 hours, about $12 ($0 on a free cluster L40). On each of the five training-row sets, switch off a set of neurons the model uses on those rows (input weights zeroed), three choices of set, sized like the real fine-tunes; and random changes at three sizes covering the fine-tunes' range, three draws each, matched within 10%. 60 readings, no fine-tuned model fetched. It tells us whether the share reads a built re-gating change near 1 and random changes lower, and whether real fine-tunes sit above random changes of their own size. If both hold, part 3 carries the share on this decomposition with the random curve as its reference and reads pair gaps at equal size; if the built change reads like random, part 3 drops the share on Qwen and says why.
  • (b) More random draws at the existing sizes. About 2 hours, about $7. Three more draws per side, 36 readings. It shows how wide the random band really is, but not whether the known-minus-invented gap is size, and still gives no picture of what re-gating reads. Most likely every pair then reads inside a wider band.
  • (c) Where each fine-tune's update lands among the neurons. About 2 hours, about $8. For the 36 saved fine-tunes, how much of each update's split falls on the neurons that fire on its own training rows, against random changes. Every fine-tune is fetched again. It would show whether fine-tuning concentrates on neurons the model already uses on that text, but part 2 has not tested such a placement reading on the small model, so its meaning would wait on that.

Its weak point: it builds re-gating by switching neurons off; switching them on, closer to eliciting a capability, cannot be built the same way. Not run: a built change that switches neurons on, any attention reading on this decomposition, the reinforcement-learning updates.

Question for you · definition-lead · new 2026-11-13

A new, tentative wording of reuse grades every fine-tune by how simply the original can be changed into it. Should it be the wording we test next?

This replaces the card on the third wording. That card recommended adopting the third wording without saying that it can return "no reading", the failure of Jain et al.'s definition that we set out to fix. That recommendation is withdrawn. The second wording stays the working definition until you choose.

The wording. F reuses M to the extent that F is M under a simple intervention on M's variables. Reuse is graded by the simplest such intervention: the shorter it is to describe, given M, the more F reuses M. The fully precise form is in the glossary, reuse as the simplest intervention.

  • Every fine-tune gets a grade. At worst the intervention rewrites the output from scratch, so there is no "no reading".
  • Any intervention is allowed, but each is charged. Complexity is the number of bits needed to name the original's variables the intervention touches and to write down its numbers, provided the result matches the fine-tune within a fixed KL tolerance. KL measures fidelity, not complexity. A re-setting costs a few bits, a new trigger a few more, and new computation costs about as much as starting from scratch.
  • The definition itself is general. Linear reads, affine edits and a list of the original's variables are measurement choices only.

Expected readings, by argument. Do-nothing and built re-settings read as reuse (do-nothing costs nothing). A random-bit floor reads as new. A memorised fact reads as new, or as a new trigger if the original already has a variable that picks out its trigger.

Limits. It is relative to a description language: in practice the variable list, the precision, the tolerance and the inputs. Every measured number is a bound, so "new" means "nothing simpler was found". A memorised fact must be charged for the direction that picks it out, or it reads as cheap.

Options.

  • (a) Test it next. Recommended. About a day. After a short plan and a new cell from you, one run measures cost against KL on the built edits first, then on the fact, its twin and the old matched pairs. It shows whether built edits grade as built and where the real fine-tunes fall on the scale.
  • (b) Refine the wording first, with no run. A fresh reviewer and you go over the precise form, then (a). This delays the test by a day.
  • (c) Keep the second wording. No spend, but part 1 then never says "built" on small input sets.

Recommendation: (a). The wording is complete and general, and one run checks it against edits whose answer is known. If it goes ahead, you choose the variable list (neurons, components or principal directions), the precision and the KL tolerance.
