Nothing runs until this is decided.

When teacher training is repeated along a fine-tune, may we read how far the subcomponents moved as what the fine-tune taught?

The question and evidence. Each round of a repeated run starts from the last round's subcomponents and copies the fine-tune at a later step. We ran 1,000 more steps with the unchanged model as the teacher: its predictions came back (KL 12.4 to 0.06 nats) but its weights did not (largest relative change 0.018 to 0.021), and it still passed the check (0.96). A real round grew by the same 17%, so that growth happens with nothing to copy. Each state's check and kept behaviour stand.

Options. (a) Change the wording only: stop reading size as piled-up error or as the update; $0. (b) The wording, plus a repeated run with nothing to teach (one free cluster job, 35 minutes): if it passes at the same size, size says nothing; if it fails, repeating harms by itself. (c) The wording, plus a repeated run that keeps the optimiser's memory between rounds (same cost): shows whether restarting costs accuracy.

Recommendation: (a). No running plan repeats teacher training. Run (b) first if the larger model's plan does.

How should the scaled adjoint split's loss of behaviour be worded?

The question. At the same update size a faster SGD run keeps 0.08 to 0.09 more of the behaviour than a slower one, on both seeds. The size-only test could not be scored: a shrunk update loses the behaviour itself.
