On Qwen3-1.7B the pass test cannot fail any state that holds the fine-tuned weights. How should it change?

Evidence. Γ computes its masks again from each state's own activations, which carry the update for any state holding the fine-tuned weights. So doing nothing, with the whole update left in Δ, sat 0.09 nats from the fine-tuned model against 1.42 for the original decomposition: it kept 97.5% of the update where about none was expected, as does a split onto either half, so no split can be scored (E44).

Options. (1) Γ reads the original model's activations for every state (reading B, set aside on 2026-10-19): a split is scored by what the moved subcomponents carry at the old gates, and do-nothing reads 1.42 by definition. Blind to a split onto subcomponents Γ switches on only after the update; the split states are rebuilt first (about 35 min, $0 on an L40). (2) Not closeness: the cost of the masks, or VPD's own losses with Γ refit per state (about $10 a state). (3) Descriptive placement only (where the update lands, against a random change): $0, no pass line. Options 1 and 2 change your 2026-10-19 pass criterion.

Fable's recommendation (Fable's, not the lead's). Option 1, put as the choice it is: on Qwen reading A is passed by the masks alone, do-nothing included.
