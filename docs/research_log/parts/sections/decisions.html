Adopt the refined new-versus-existing rules that E99 tested on the old 67M tasks?

The question. The new-versus-existing definition is what the Qwen readings are read against. Adopt E99's refined rules, or keep the definition?

The evidence. Copying reads as built: forced through the two copying heads a fine-tune has all its gain there, forbidden from them none. Lowercase has no working check (forced, it reaches 0.6 of the gain). The class map and token tasks fail admissibility (removing their capability costs a hand-built reader of the input 0.42 against a band of 0.16). Only copying gets a verdict.

The six rules, in brief (full text: section "Rule changes proposed to the user" of the E99 report, reports/analyses/2026-11-05_analysis_e99-definition-verify.md).

  1. Net share for a located part: the gain lost with the part switched off, minus what the original model loses from the same switch-off, over the gain; one random band per fine-tuned model. A constant-answer task gets a verdict through a part only if switching it off costs the original model its own leaning beyond the band, and the part does something input-dependent. A verdict counts only after a fine-tune forced through the part reads 1 and one kept off it reads inside the band (both held on the copying heads).
  2. Lowercase fallback: if the forced fine-tune cannot reach the normal gain, the check has no positive control and the task stays "does not apply" (lowercase: 0.61 and 0.64 of the normal gain).
  3. Input dependence is read on cased rows only, as the plan worded it.
  4. Admissibility, before any band: the capability maps several inputs to each value (at least 2 per value on average, more than one value), and a downstream reader of the input token alone stays inside its band when the part is removed; a site whose reader was never read is "unreadable", never a pass.
  5. One band per fine-tuned model, compared across models by a paired test; bands are pooled only if their redraw spread exceeds the gap between them.
  6. The code writer's choices made into rules: "input" in rule 4 means what the capability is a function of; the pooling terms as in rule 5; the hand-written control is each model's own table written at block 1, a share over 0.2 stops the run; at a head pair, the forced and forbidden fine-tunes stand in for the teeth check.

Options. (A, recommended) Adopt rules 1 to 5 above as written, and rule 6's choices too. The verdict table stays as E99's; Qwen readings use the same rules. Next: nothing runs. (B) Adopt 1 to 5 and send rule 6's choices (what counts as an input, the pooling terms, the hand-write control) back for a separate look. Next: a short look, no run. (C) Keep the current definition (decisions.md rows 81, 115 to 121) and file E99 as a check only. Next: nothing runs.

Recommendation: A. Each rule was tested where the answer is known and only narrows what gets a label.
