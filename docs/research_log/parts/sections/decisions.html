Question for you · definition-lead · new 2026-11-18

Should a fine-tune that adds a small new trigger in front of an old, unchanged circuit count as reuse?

Nothing runs until this is decided: the known-answer test (2 runs, due 2026-11-20) is held, and its predictions are filed only after your answer. M is the original model, F its fine-tune; the definition says F reuses M, for a behaviour at a declared level, to the extent that the parts F needs still compute what M's parts compute on the same inputs.

  • Measured so far. The neuron-level score saturated: 0.999 or more on every fine-tune (E208), not expected. The held-model reading separated only items new by construction (a graft 0.13, the rebuilt circuit 0.56) from old-task fine-tunes (0.98 or more). The held test would read four hand-built edits with known labels at neuron, head, MLP-layer and block level, which nothing has done.
  • The case. M copies B after a repeated A through two attention heads (its induction circuit). One reuse edit adds eight first-layer neurons that make a new cue A′ look like A; the unchanged heads then copy B. As written, the parts F needs are found by giving every part M's rule and handing F's rule back to as few parts as possible until the behaviour returns. An unchanged part is not moved by that swap, so the heads never enter the set: only the new front end does, and it does not keep M's rule. The edit reads "not reused", the same as an edit writing a new answer into the same eight neurons, at every level and under every decomposition.
  • So the definition now answers "did the edited parts keep their rules?", not "how much old machinery does the new behaviour run through?".

Options (no recommendation: this is your definition question). (a) Keep it as written. The test runs as planned and mostly confirms a derivation: no coarse level separates (the three concentrated edits all read 0), and the neuron level reads the thinly spread new edit highest. The paper says reuse describes how the change was made; lost: a re-triggered old circuit reads as new, and the trained pairs are not read at a new level. (b) Count every part the behaviour runs through in F, changed or not. The unchanged heads count as kept; the planner's estimate is about 2/3 for this edit at block level and near 0 for the new edits, so the test could pass and the trained pairs would then be read at that level. It needs a new clause in the definition, in your words. Your answer (2026-11-18): if every part counts, an unneeded part is replaced by its mean over the behaviour's inputs. (The other option was its value on another input, a resample.)

Second, smaller question (you said "I don't know"; you may hand it back to the lead). When we test whether a part of F still follows M's rule, we feed the part an input and compare its output with M's version of that part. Which input do we feed it? Take the example above.

  • (A) What reaches the part in F's own run. F has learned to make the new cue A′ look like A in layer 1, so the unchanged induction heads receive "looks like A". M's copy of those heads, given the same thing, would also copy B. Same output, so the heads read as kept. This asks: did the part's own computation change?
  • (B) What reached the part when M read the same text. M never learned A′, so in M the heads received plain A′ and did nothing. In F they copy B. The outputs differ, so the heads read as not kept, even though their weights never changed. This is activation patching (Prakash et al. 2024). It asks: does the part behave the same on this text as it did in M?

Under B, any reuse that runs an old circuit on a new cue reads as new, because M never ran the circuit on that cue. Under A, it can read as reuse. Lead's recommendation: A, because only A can tell "same machinery, new cue" from "new machinery". Both are reported either way; the choice sets which one the pass rule uses. It matters only if the main answer is (b).
