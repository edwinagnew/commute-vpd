Reuse line: score VPD now, or first fix the truth set and the cut-offs?

The question. Three methods without a decomposition were scored on 26 fine-tunes. None beat a labeller that reads only the learning rate; pruning and steering came one state short. The truth set is tangled with the recipe, so any method, VPD included, can beat that labeller by only a few states. After the fact each raw reading splits the two sides cleanly: the cut-offs failed.

Options. (1) Score VPD now on the same truth set (a gated run, about $10 to $30, cluster rehearsal first). (2) First, at $0, rerun the three methods with cut-offs set on states outside the truth set, and build a truth set where reuses are read late and new states early; then decide on VPD. (3) First the bounded-readings stage on the 67M fine-tunes ($0). Recommendation: (2), since on this truth set even a perfect VPD beats the labeller by at most 7 of 26 states.

The question. At the same update size a faster SGD run keeps 0.08 to 0.09 more of the behaviour than a slower one, on both seeds. The size-only test could not be scored: a shrunk update loses the behaviour itself.
