Should a fine-tune that adds a small new trigger in front of an old, unchanged circuit count as reuse?

Nothing runs until this is decided: the known-answer test (2 runs, due 2026-11-20) is held, and its predictions are filed only after your answer. M is the base model, F its fine-tune; the definition says F reuses M, for a behavior under a declared featurizer, to the extent that the variables F needs still have M's mechanisms on the settings of their parents that occur.

  • Measured so far. The score with single neurons as variables saturated: 0.999 or more on every fine-tune (E208), not expected. The held-model reading separated only items new by construction (a graft 0.13, the rebuilt circuit 0.56) from old-task fine-tunes (0.98 or more). The held test would read four hand-built edits with known labels with neurons, heads, MLP layers and blocks as variables, which nothing has done.
  • The case. M copies B after a repeated A through two attention heads (its induction circuit). One reuse edit adds eight first-layer neurons that make a new cue A′ look like A; the unchanged heads then copy B. As written, the circuit F needs is found by giving every variable M's mechanism and handing F's mechanism back to as few variables as possible until the behavior returns. A variable whose mechanism did not change is not moved by that soft intervention, so the heads never enter the circuit: only the new front end does, and its mechanism does not agree with M's. The edit reads "not reused", the same as an edit writing a new answer into the same eight neurons, under every featurizer.
  • So the definition now answers "did the edited variables keep their mechanisms?", not "how much old machinery does the new behavior run through?".

Options (no recommendation: this is your definition question). (a) Keep it as written. The test runs as planned and mostly confirms a derivation: no coarse featurizer separates (the three concentrated edits all read 0), and the neuron featurizer reads the thinly spread new edit highest. The paper says reuse describes how the change was made; lost: a re-triggered old circuit reads as new, and the trained pairs are not read under a new featurizer. (b) Count every variable the behavior runs through in F, changed or not. The unchanged heads count as agreeing; the planner's estimate is about 2/3 for this edit with blocks as variables and near 0 for the new edits, so the test could pass and the trained pairs would then be read under that featurizer. It needs a new clause in the definition, in your words. Your answer (2026-11-18): if every variable counts, an unneeded variable is replaced by its mean over the behavior's inputs. (The other option was its value on another input, a resample.)

What the literature does (from a review of the definition, 2026-11-18, its section 4). Circuit analysis counts every variable the behavior runs through: Geiger et al.'s sub-circuit analysis (their section 3.5.2) ablates everything outside a minimal circuit to fixed values and asks whether the circuit still produces the behavior, which is option (b). Your replacement rule, the mean over the behavior's inputs, is standard mean ablation (Wang et al. 2023); resampling (Chan et al. 2022) is the other standard. This is context only; the main question stays yours, with no recommendation.

Second, smaller question (you said "I don't know"; you may hand it back to the lead). When we test whether a variable's mechanism in F agrees with M's, we give the mechanism a setting of its parents and compare its output with M's mechanism on the same setting. Which settings do we use? Take the example above.

  • (A) What the parents take in F's own run. F has learned to make the new cue A′ look like A in layer 1, so the unchanged induction heads receive "looks like A". M's mechanism for those heads, given the same thing, would also copy B. Same output, so the heads read as agreeing. This asks: did the variable's own mechanism change?
  • (B) What the variable took when M read the same text. M never learned A′, so in M the heads received plain A′ and did nothing. In F they copy B. The values differ, so the heads read as not agreeing, even though their weights never changed. This is activation patching (Prakash et al. 2024). It asks: does the variable take the same value on this text as it did in M?

Under B, any reuse that runs an old circuit on a new cue reads as new, because M never ran the circuit on that cue. Under A, it can read as reuse. Lead's recommendation: A, because only A can tell "same machinery, new cue" from "new machinery". Both are reported either way; the choice sets which one the pass rule uses. It matters only if the main answer is (b).

What the review adds here (its sections 3 and 4). The decided wording already says that, given the same setting of its parents, the variable's mechanism in F gives the same output as in M. That compares two mechanisms on the same settings, which is A, the standard meaning of "same mechanism" in causal models. B compares the values a variable takes in two solutions, as activation patching does, so choosing B would change decided wording. What is really open is whose settings the comparison uses: those in F's solutions, those in M's, or both pooled. The review suggests pooled, since the standard is the settings that occur on the data.

When a featurized model fits the fine-tune only approximately, should we run the test inside the featurized models?

M is the base model, F its fine-tune, and F̃ and M̃ are their featurized models.

  • The case. When ε is above zero on F, F̃ does not reproduce F exactly. The test "does this circuit preserve the behavior?" can then be run against F itself, or against F̃. Without a choice the definition could fail to give an answer.
  • Measured so far. Nothing: all readings are exact, ε = 0, and there the two choices coincide, so no reading changes.

Options. (a) Compare inside the featurized models: run the test on the intervened model of F̃ and compare it with M̃, so the definition gives an answer in every case. The review's repairs are quoted in its older words, where a "part" is a variable and F_K the intervened model.

  • 1. Set aside (you chose one fixed featurizer, 2026-11-18). Should the featurized model of F be allowed to use F, if the rule for doing so is fixed before any reading? No: the featurizer (τ0, σ0) is fixed from M alone and F's features are not fitted (box). The question as it stood: the definition says the featurizer is fixed from M alone. But reading VPD components on F means splitting F's weight change over them, and every useful split is computed from that change; only the do-nothing split is not, and it reads every change as new. A crosscoder, trained on both models at once, breaks the same rule. Review's repair: "F̃ is produced from M̃ and F by a rule declared before any reading (the same encoder; a named split of δW), never chosen to change the reading." No reading changed. Closed by your choice.
  • 2. Should every variable outside U, the output above all, take M's mechanism in every intervened model? The soft intervention from the base model gives M's mechanism only to variables in U; the output layer and any glue keep F's. A fine-tune that changed only the unembedding then preserves its behavior with every variable in U on M's mechanism, so it needs no variables, and "the soft intervention on all of U gives M" is false. Review's repair: "Every variable of N other than the input lies in some part's cell; or, the output (and any non-part variable) runs M's mechanism in every F_K." Content, a missing clause; the 67M readings already set the output to M's, so none is expected to change. Lead: accept, in the second form.
  • 3. Should every reading report how much of the circuit F needs is remainder? With a remainder variable the featurized model is exact for any encoder, so ε is always 0. A weak SAE pushes F's change into the remainder, which becomes the needed variable; the reading says "new" and ε hides why. Review's repair: "report, beside ε, either the share of K that is remainder (the level note's Part B proposal) or ε of the same decomposition with its remainder removed." Changes what is reported, not the definition; no reading used a remainder. Lead: accept, with the remainder's share.

If variable a has parent b in F̃ and b has parent a in M̃, the soft intervention on b alone makes a cycle, and the intervened model cannot be run in layer order. Every current case follows layer and position order. Review's repair: "one clause requiring a shared causal order." No reading. Closed.
