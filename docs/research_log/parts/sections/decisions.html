Should a small new trigger in front of an old, unchanged circuit count as reuse?

Nothing runs until this is decided: the known-answer test (2 runs, due 2026-11-20) is held; its predictions are filed after your answer.

The case. M, the base model, copies B after a repeated A through two attention heads. A hand-built fine-tune F adds eight first-layer neurons that make a new cue look like A, and the unchanged heads then copy B. We built this as a reuse case.

Why the definition calls it "not reused". The definition finds the variables F needs like this: give every variable M's mechanism, then hand F's back to as few variables as possible until the behavior returns. Handing F's mechanism back to the two heads changes nothing, because theirs is the same as M's, so the heads are never in the set. Only the eight new neurons are, and their mechanisms are not M's, so the edit scores as not reused. This is separate from single neurons being too low-level, which you settled: it holds with heads, layers or blocks too.

Options (no recommendation: this is your definition question).

  • (a) Keep the definition as written. Runs: the test as planned, $0 to about $3.50. Tells you: the test reads four hand-built edits, two built as reuse and two as new; predicted: with heads, layers or blocks as variables, the trigger edit and both new edits read 0, so no coarse level tells reuse from new. In the paper, reuse says whether changed variables kept M's mechanisms, not how much old machinery the behavior uses. Lost: a re-triggered old circuit reads as new; a behavior M already shows gets no score (no variable is needed); with coarse variables, reward hacking and emergent misalignment read as new. Next: the five trained fine-tune pairs are not read.
  • (b) Count every variable the behavior runs through in F, changed or not. Runs: the same test plus a step removing unneeded variables by your rule (their mean over the behavior's inputs), cost not estimated. Tells you: the plan estimates a reuse score of about 2/3 for the trigger edit with blocks as variables (the block with the new neurons disagrees with M, the two with the old heads agree) and near 0 for the new edits, so the test can pass or fail. Gained: it counts as circuit analysis does; reward hacking and emergent misalignment read mostly reused. Lost: a memorised fact also reads mostly reused; the definition needs a new clause in your words. Next: if a level recovers all four labels, the five trained pairs are read once at it (under $1); if none does, they are not.

Neither option gives a separate label for a newly created mechanism; both only grade from reused to not reused.
