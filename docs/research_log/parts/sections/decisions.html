Which comes first: a harder counting test for the cheap methods, or a causal label for the 67M model's fine-tunes?

The question. The method table (section {{n:methodtable}}) scores each method against a label per fine-tune: does the behaviour run through a mechanism the unchanged model already has (reuse), or not (new)? On the counting fine-tunes three methods scored 21 of 21, but anything that reads which task a state was trained on would too, since task and label coincided. A harder counting test is drafted and reviewed by Fable; nothing has run.

The evidence. The harder test trains the same two tasks on two bases, each counting one letter, so each task reuses on one base and is new on the other; the label comes from copying the unchanged model's internal state into the fine-tuned one. Fable's advice (not ours): it can rank cheap methods but VPD cannot win, since a reader of answers ties every cell, and the plan's pass rules in effect need 8 of 8 cells. Fable also found that the copying check used on the earlier counting row reads 0 by construction on a state that does not answer the patched count, so "new" there rests on behaviour. No label moved.

Options. (a) Run the harder test with Fable's changes: two new bases, about 52 fine-tunes, three cheap methods scored. $0, 3.5 to 6 hours of free cluster jobs. Tells us which cheap methods read reuse once the task stops giving it away; next, the survivors go to the 67M model, VPD stays out. (b) First plan the same copying check on the 67M model's fine-tunes, where VPD already has readings. Nothing runs until that plan is reviewed. It gives those rows a causal label, so VPD can be compared with cheaper methods; next, write and review the plan, then run it. Limit: fewer rows than the counting set.

Recommendation: (b). Only (b) can show VPD winning or losing, the merged line's question; run (a) later if the cheap-method ranking is still wanted.

When teacher training is repeated along a fine-tune, may we read how far the subcomponents moved as what the fine-tune taught?

The question. Teacher training can be repeated: each round starts from the last round's subcomponents and copies the fine-tune at a later step. It is our only test of keeping a decomposition current along training, and we have read the size each round reaches as error piling up or not. We now have a first reference for a round with nothing new to copy.

The evidence. We took the decomposition after one teacher training and ran 1,000 more steps with the unchanged model as the teacher. Its predictions came back (KL to the unchanged model 12.4 to 0.06 nats) and it passed the adversarial check, at 0.96. Its largest relative weight change grew from 0.018 to 0.021, though about a quarter of the original direction was undone; from a random start of that size it grew to 0.023. In the real repeated run (another card) the last long round grew by 17% and the one before by 52%. So some growth happens with nothing to copy, and this one pair cannot say how much. The check and kept behaviour are read on each state, so they stand.

Options. (a) Change the wording only. Nothing runs, $0. We keep "each state keeps the behaviour and passes", and do not read size in either direction until a repeated run with nothing to teach exists. It does not tell us how such a run would read. Nothing follows. (b) The same wording, plus a repeated run with nothing to teach: seven rounds of 100 steps against a fine-tune whose labels come from the unchanged model's own predictions. One free cluster job, about 35 minutes. We read it against a single round at the same three adversary starts, 1.40, 1.37, 1.29. If the filed three-start test calls it apart from that round, repeating harms by itself, and any repeated run on the larger model needs a new recipe first; if within noise or below, repeating adds no harm we can see, and size in repeated runs says nothing either way. One task, one label draw.

Recommendation: (a). No plan repeats teacher training now, and no pass depends on reading size. Run (b) first if the larger model's plan chooses repeated rounds.
