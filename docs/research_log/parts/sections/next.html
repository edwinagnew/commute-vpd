Re-gating: does Γ's new gating describe the fine-tuned model?

What re-gating is. Γ reads the fine-tuned model's shifted activations at the trigger and switches on other original subcomponents, which then predict the target about half-way. For: the switched-on set is target-specific, and fine-tune, LoRA and component training switch on the same one (E6, E18). Against: a change that compounds across layers also reads as re-gating, the set carries under half the effect (E4, E6, E18), a fine-tune that learned nothing read the same share (E36), and no Γ fitted to the new model exists (E15).

Next. Pieces ranked by pull toward the target take back at least as much of the gain as the switched-on set at the same count; Γ finds a set rich in them without the target (E38). The user closed the 67M restore line on 2026-10-28; no re-gating runs are pending.
