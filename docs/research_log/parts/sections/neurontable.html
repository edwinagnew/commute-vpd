Neurons and cheap comparators beside VPD

Takeaway (2026-11-06). On the 67M, VPD's re-gating share r separates copy maps from random maps and lowercase from the ciphers, while the same reading done on neurons reverses on the first pair and falls short of the bar on the second. On Qwen3-1.7B, VPD's reading does not order which updates pass the least-squares map's faithfulness table (E93), while update size, gain and the carrying-neuron share do; so VPD's added value over cheap numbers is so far a 67M finding.

This table predates E131 (the new Qwen decomposition), E133 (the current comparison of the share with simple baselines) and E144 (the share on Qwen in log-odds). Read it as the record of 2026-11-06.

What this is. Every VPD reading we have on the 67M re-gating states and on the Qwen3-1.7B fine-tunes, each beside the same reading done on neurons and the cheap comparators: update size, the original model's rank of the answer, the steering share and the carrying-neuron set. Provisional: the independent check holds with caveats.

Source. Copied, with no verdict re-scored, from experiments/neuron_vpd_table/results/full_table.md (built by experiments/neuron_vpd_table/build_full.py from result files only). The per-row file paths of the Qwen tables stay in that file and are left out here. Legend. does not apply (n/a): a constructed control with no trained state, so a comparator has nothing to read. unreadable (a dash): the reading has no input, for example VPD's switched-on set is empty (K = 0) so every set panel on lowercase and the ciphers is unreadable for both methods. rows differ: the Qwen comparators read each arm on its own rows (template rows, TOFU rows, gold maths solutions, or the arm's own sentences), so part of a comparator's gap between two arms is a gap between rows; VPD's maths rows are shared. A gap over seed spread above 1 is the stop rule's "counts".
