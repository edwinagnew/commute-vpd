The neurons-against-VPD question, in one table

Neurons and cheap comparators beside VPD

What this is. Every VPD reading we have on the 67M re-gating states and on the Qwen3-1.7B fine-tunes, each beside the same reading done on neurons and the cheap comparators: update size, the original model's rank of the answer, the steering share and the carrying-neuron set. Provisional: the independent check holds with caveats.

Source. Copied, with no verdict re-scored, from experiments/neuron_vpd_table/results/full_table.md (built by experiments/neuron_vpd_table/build_full.py from result files only). The per-row file paths of the Qwen tables stay in that file and are left out here. Report reports/analyses/2026-11-06_analysis_e117-e118-neurons-beside-vpd.md; check reports/reviews/2026-11-06_review_e117-e118-independent-check.md. Cards: E117, E118.

Legend. does not apply (n/a): a constructed control with no trained state, so a comparator has nothing to read. unreadable (a dash): the reading has no input, for example VPD's switched-on set is empty (K_VPD = 0) so every set panel on lowercase and the ciphers is unreadable for both methods. rows differ: the Qwen comparators read each arm on its own rows (template rows, TOFU rows, gold maths solutions, or the arm's own sentences), so part of a comparator's gap between two arms is a gap between rows; VPD's maths rows are shared. A gap over seed spread above 1 is the stop rule's "counts".
