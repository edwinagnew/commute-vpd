Can teacher training copy a behaviour the model did not have before, pass the faithfulness checks and leave Δ alone?

2026-10-28 · MATS cluster L40 · experiments/teacher_training

The question. Q4 asks whether it matters that a fine-tune teaches something new. Teacher training trains the decomposition's pieces to match a finished fine-tune, with Γ and Δ frozen. Γ gives each piece an importance between 0 and 1 at each position; Δ holds the residual weights. The masked model keeps only the pieces, each scaled by its importance, with Δ left out. In E34 it copied six fine-tunes faithfully, but each taught something the model already half did.

What we did. E10's fine-tunes teach a word cipher. Each window holds a marker never seen in ordinary text, then a key word; at that position, the trigger, the model must put the key's value next. Tasks: 32 random pairs, one random pair, and an identity control (each key followed by itself), which the model half does already. We copied each fine-tune on the task's 403 training windows, and again on plain Pile text; the cipher is read on 97 held-out windows. References: do-nothing leaves the fine-tune in Δ; the least-squares split gives the pieces the smallest change that fits and the rest to Δ. The adversarial ratio is the damage a mask-searching adversary finds on Pile text, over the unchanged decomposition's; here it passes at 1.24 or below, fails at 1.81 or above, from the unchanged decomposition's spread over adversary seeds.

What we found. The task-text copy keeps the cipher (0.96 to 1.00) and passes on all three tasks (first figure). Δ stays untouched by construction, since teacher training freezes it; the test is that the behaviour went into the pieces anyway. But the masked model at the trigger loses both random ciphers: 0.007 where the copy reads 0.96 (second figure). Surprise: a copy trained on Pile text alone reached 0.91 on the one-pair cipher, where we expected below 0.5 (third figure).

What it means. The criterion in force (reading A, decisions.md) asks that the mapped decomposition pass VPD's own checks on ordinary text about as well as the unchanged one does, with the whole model keeping the behaviour and Δ not absorbing the update. The copy passes as a map by that criterion, yet its masked model loses the cipher; that loss is the open problem. The masked model loses it too for do-nothing, the least-squares split or E10's component training on the task's labels. Four masked versions of teacher training meant to fix this were run only with nothing to copy, broke the check there, and so never ran on the cipher (fourth figure): whether any map with Γ fixed can do it is untested. One seed, one batch order, one adversary start.

Run
E10's cipher fine-tunes (Adam 3e-5, seed 0, 1,000 steps) were each copied by 1,000 steps of teacher training on task windows or Pile rows, beside do-nothing and the least-squares split, controls first, all passed. Five MATS cluster jobs, $0.
Found
  • On all three tasks the task-text copy keeps the cipher and passes with Δ untouched, as expected.
  • On both random ciphers the masked model keeps almost none of it, as expected and as with E10's component training on labels. Four masked recipes meant to change that were run only with nothing to copy; all broke the check there, so none ran on the cipher.
  • Unexpected: Pile text alone taught the one-pair cipher (0.91), on one batch order; cause untested.
