The question. The re-gating line needs a reading that tells a fine-tune that elicits something the original model already does from one that teaches something new. E52 found that one added steering vector separates a copy task from a map, perhaps only because copying does not depend on the key. The user chose (2026-10-30) a pair where both tasks depend on the key.

What we did. Code and predictions are filed; nothing has run. Both are fine-tuned on E12's recipe (two seeds), the cipher read at the step whose update has the same size as the elicit map's. Each is then read two ways: steering with one mean vector (E52) and the route split's re-gating share r (E46).

What it means. If r separates the pair while steering cannot, r is reading more than the key-independence of the task, which E53 could not show. A miss would say the earlier separation came from the task or its breadth. An independent code review and two $0 cluster jobs come first.
