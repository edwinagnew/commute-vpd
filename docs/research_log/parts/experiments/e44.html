Qwen3-1.7B: can the pass test fail a bad placement, and how do simple splits of E40's update read on it?

2026-10-29 · RunPod A100 SXM · experiments/qwen_maps

The question. On the commute line's larger model (Q9), the plan first checked that the pass test, VPD's faithfulness check plus closeness to the fine-tuned model, can fail a bad placement of an update, before reading any real split of E40's maths fine-tune. A test that cannot fail anything says nothing about a pass.

What we did. We put E40's weight change after 10 steps into the subcomponents in three bad ways: onto the subcomponents Γ rarely turns on for maths text, as a random change sized like the update, and not at all (do-nothing, the whole update left in Δ). Each state's masked model was read against the fine-tuned model on 128 maths rows, with Γ recomputing its masks from each state's own activations. A first paid run stopped on a precision rule; the fix was rehearsed at $0 and the run repeated.

What we found. The unchanged decomposition reproduced itself, but do-nothing sat 0.09 nats from the fine-tuned model, against 1.42 for the original model's masks, so it kept 97.5% of the update where the plan expected about none. The lower-half split read the same, and the random change did not hurt at all (largest ratio 1.0004). The code is right: Γ reads the fine-tuned model's activations for any state holding the fine-tuned weights, and its masks alone bring the masked model close to it.

What it means. As built, the pass test cannot fail a state that holds the fine-tuned weights, so no split of this update can be scored on it. Per the plan the line stops; changing what the test reads changes the pass criterion fixed on 2026-10-19, which is a question for you (section {{n:decisions}}). Whether Γ's new masks describe the update or only copy the fine-tuned model's output is untested on Qwen.

Run
Stages C, S, D and K ran on an A100 SXM (US-MO-1) for $3.66 ($6.14 with the first pod); E40's weight change was remade on the cluster and put on W&B. It stopped at stage K, after the control, per its filed rule.
