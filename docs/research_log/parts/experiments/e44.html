On Qwen3-1.7B, can the pass test fail a deliberately bad placement of a fine-tuning update?

2026-10-29 · RunPod A100 SXM · experiments/qwen_maps

The question. The commute line asks whether a fine-tuning update can be moved into a decomposition's subcomponents so that the decomposition stays faithful and still does what the fine-tuned model does (the weak version), and whether that carries over to a larger model. On Qwen3-1.7B, E40 made the update: ten steps of fine-tuning on maths answers. Before scoring any real way of placing it, the plan checked that the pass test can fail placements that are bad on purpose. A test that passes everything says nothing when it passes a split.

What we did. The decomposition writes each weight matrix as a sum of subcomponents plus a residual, Δ. Its importance function, Γ, reads the model's activations and sets a mask per token: how much each subcomponent is switched on. The masked model runs on the masked subcomponents with Δ off. The pass test reads three things. Two are faithfulness ratios: how far the masked model is from its own full model, and how much damage a saved adversary does. The adversary is a set of masks found earlier to hurt the unchanged decomposition most. Each reading is divided by the unchanged decomposition's, so 1 is as good as before and above 1.5 fails. The third is the share of the update kept: the original decomposition's distance from the fine-tuned model (masks from the original model's activations) minus this state's, divided by the original decomposition's distance minus the floor (the original model against its own masked model), so 0 means it keeps none of the update and 1 means it is as close as the floor, with 0.8 needed to pass. Three bad placements were read after 1 and 10 steps on 128 maths rows and 128 web rows. Do-nothing leaves the whole update in Δ, so its subcomponents are the original ones. Two halves move the update onto the half of each matrix's subcomponents Γ rarely switches on for maths text, or the half it often does. A random change of the update's size goes onto the subcomponents instead. In every state Γ computes its masks from that state's own activations.

What we found. Do-nothing kept about 97% of the update where the plan expected about none, and both halves read the same (second figure). The first figure shows the cause directly: with the same original subcomponents and Δ off, changing only whose activations Γ reads, the original model's or the fine-tuned model's, moves the masked model from 1.42 nats away from the fine-tuned model to 0.09. A state holding the fine-tuned weights gets the second kind of masks; reading the code ruled out a bug as another route (reports/analyses/2026-10-29_analysis_e44-no-teeth.md). The random change keeps none of the update, as expected, but leaves both faithfulness ratios at 1.0, so they do not catch it (third figure). The test did fail do-nothing and the halves at step 10 on one ratio, the masked-model ratio on maths rows, at 1.58 against the 1.5 line. The filed control did not count that: it judged do-nothing by the share kept, the reading built to catch an update left out of the subcomponents, which read 97%.

What it means. As built, the pass test cannot fail a state that holds the fine-tuned weights: Γ reads that state's own activations, which are the fine-tuned model's, so the share-kept reading passes it whatever the subcomponents hold. That was seen on all three such placements, on one seed, at steps 1 and 10. With its controls unable to fail, the plan's rule allows no split of this update to be scored on it, and none of this is evidence for or against the weak version. Per the plan the line stops. Changing what the test reads changes the pass criterion the user fixed on 2026-10-19, so it went to the user (section {{n:decisions}}). Fable, an advising agent, recommends scoring every split with masks from the original model, after a $0 check of whether the masks describe the update or only copy the fine-tuned model's output. That check has run (Amendment 1, fourth figure): they copy it. Given the fine-tuned model's activations only up to layer 16, which already make 93% of the update's effect on the output, Γ's masks reproduce none of it (-0.003); they reproduce it only when Γ also sees the last layers (0.31 at layer 24, 0.99 from the residual stream alone). So do-nothing's pass comes from Γ copying the output, which supports the user choosing option 1; the choice is still the user's.
