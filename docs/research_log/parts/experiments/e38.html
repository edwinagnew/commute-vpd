Does the fine-tuned model itself use the subcomponents Γ switches on?

2026-10-27 · RunPod RTX 4090 · experiments/recruitment_test

Partly: the switched-on subcomponents already push toward the target in the original model, and after the fine-tune the model loses a tenth to a quarter more of its gain without them on two of three tasks, more than for any random set. But a set switched on by a fine-tune to a different token shows some of the same, so the extra loss is not shown to belong to this set.

Run
E18's three tasks (emoticon, which-was, we-just), two seeds each, with a 10-step fine-tune to http at the same triggers as the null. Each state was regenerated, and the switched-on set (the alive subcomponents whose importance at the trigger rises by more than 0.3) was subtracted from the real weights at every position, on held-out windows. Read beside 20 random same-size sets, the http fine-tune's set, a set of the busiest subcomponents, and the same removal from the original model. Stage 0 first: it reproduced E18 on its second run, after its first stopped on a tolerance taken from reloaded states. Then an input trace and a census of where the set is on in Pile text. About $0.23 in all. Amendment 2 (cluster L40, $0) removed the set at the trigger position only, from both models, and scored the fine-tuned minus original share of the gain against 20 random sets, the ` http` fine-tune's set and a busy set; a census over about a million Pile positions counted how many of the set's pieces are followed by the target.
Found
  • At the trigger, the fine-tuned model loses 0.23 to 0.25 more of its gain than the original without the set on emoticon and 0.12 to 0.19 on ` which`, above all 20 random sets; on ` we` the difference is about 0. The original model already loses 0.14 to 0.27 of the gain without the set, which first made us doubt the test.
  • The controls blunt it, against the filed prediction: the ` http` fine-tune's set reads 0.10 to 0.14 on the same two tasks, equal to the set's own on ` which` seed 0, and the busy set 0.78 to 1.10, while random sets are mostly off at the trigger. So the set matters at the trigger, but the gain running through it is not separated from the fine-tune amplifying whatever is active there.
  • The set is the original model's own machinery: 60 to 96% of its pieces are followed by the target in Pile text far more than chance, against 2 to 8% of random pieces. The enrichment is partly shared with the other word target and does not separate ` we`, where the difference is 0.
