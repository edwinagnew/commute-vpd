Does the fine-tuned model itself use the subcomponents Γ switches on?

2026-10-27 · RunPod RTX 4090 · experiments/recruitment_test

Partly, but those subcomponents already push toward the target before any fine-tuning, so the test cannot say how much of the fine-tune works through them. Removing the switched-on set from the fine-tuned weights takes away a third to a half of the gain on two of three tasks (blue dots in the figure), far more than random sets of the same size. Removing it from the original model, where we expected nothing, already takes away a sixth to a quarter (green circles).

Run
E18's three tasks (emoticon, which-was, we-just), two seeds each, with a 10-step fine-tune to http at the same triggers as the null. Each state was regenerated, and the switched-on set (the alive subcomponents whose importance at the trigger rises by more than 0.3) was subtracted from the real weights at every position, on held-out windows. Read beside 20 random same-size sets, the http fine-tune's set, a set of the busiest subcomponents, and the same removal from the original model. Stage 0 first: it reproduced E18 on its second run, after its first stopped on a tolerance taken from reloaded states. Then an input trace and a census of where the set is on in Pile text. About $0.23 in all.
Found
  • Removing the switched-on set from the fine-tuned weights takes away 0.50 to 0.54 of the gain on emoticon, 0.32 to 0.36 on which-was and 0.17 to 0.22 on we-just; random sets average near 0 and the http set takes at most 0.13. The filed pass was met on no task, because one random draw on emoticon reads 0.26.
  • Against a high-confidence prediction, removing the set from the original model, where it was expected to do nothing, takes away 0.14 to 0.27 of the gain on all six states, more than from the fine-tuned model on we-just. It also disturbs the 40 other positions 6 to 22 times as much as the fine-tune itself on two tasks. An independent check found no code error: the set is chosen by a rise in importance, with no bound on its importance before, and the removal acts at every position.
  • The fine-tune moves the trigger's inputs toward the target's contexts (cosines mostly 0.1 to 0.4 past the first layer), but the filed rule held only on which-was. The census's one check had no power, so it says nothing on whether the set is the target's machinery.
