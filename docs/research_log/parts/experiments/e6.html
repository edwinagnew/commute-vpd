Recruit test

2026-10-19 · RunPod RTX 4090 · experiments/recruit_test

A real fine-tune and a LoRA switch on the same pre-existing subcomponents as component training, and which ones depends on the target. How much of the gain runs through switching does not.

Run
Real updates placed do-nothing on emoticon: the fine-tune at two seeds, a one-matrix LoRA, two fine-tunes to a different target at the same trigger (the null with power), a norm-matched random update, component training's update as reference. Switched-on sets, overlaps, recovery.
Found
  • Fine-tune vs component-training set: Jaccard 0.64 (seed floor 0.93); vs LoRA 0.82; vs a different target 0.04.
  • Re-switching share 0.51 to 0.61 for every arm, nulls included: the share is not target-specific, the set is.
  • The switched-on set carries only 40% of the re-switching effect (filed prediction failed): the overlaps compare which gates moved, not what produces the behaviour.
  • A random update is inert.
  • Surprise: Γ is global, so a layer-2 LoRA moves layer-0 importance values; the filed locality gate rested on a wrong premise.
