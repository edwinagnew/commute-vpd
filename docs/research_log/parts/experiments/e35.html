Can the change in Γ's values after a fine-tune be predicted without being told the cue word?

2026-10-26 · RunPod RTX 4090 · experiments/regating_cuefree

The question. The decomposition's importance function Γ gives each subcomponent ("piece") a value from 0 to 1 on each input: how much that piece is used there. After a fine-tune, the frozen Γ reads the changed activations and switches on pieces it kept off before. This is re-gating, one of the project's two lines (Q5: is that switching a true description of how the model changed?). The line worked with the fixed-shift hypothesis: at the trigger, the position just before the target word the fine-tune teaches, the change in Γ's values is mostly one fixed change. E32 and E33 found it holds only as one fixed change per cue, the trigger word, and the user restated it so, tentatively, on 2026-10-23. But a rule that needs the cue cannot be used on ordinary text, which has no labelled cue. So this run asks whether the change can be predicted from the original model's values alone.

What we did. We rebuilt E32's and E33's six toy fine-tunes (ten Adam steps each, one seed), each read in the do-nothing state: the whole weight change is set aside in a residual the pieces leave out, so the fine-tune acts only through Γ reading the fine-tuned model. An input is a short window of text ending at the trigger. The switching effect is the rise in the target's log-odds when Γ's values at the trigger come from the fine-tuned model instead of the original. Every number is a share of what each input's own fine-tuned values give back of that effect: 0 is the original values, 1 the input's own, and above 1 means the predicted values raised the target more than the input's own did. Each held-out input (73 to 192 per task) got its own original values plus a predicted change, fitted on separate training inputs. Rules that name the cue: one change for every input, and one change per cue word. Rules that name no cue: the mean change of the 8 training inputs whose original values are nearest (the nearest rule), groups found by k-means, and a straight line per piece. The per-cue change comes in two forms. The added form, used for every rule here, keeps each input's own original values and adds the cue's mean change on top. E32's averaged form instead gives every input of a cue the same values, the cue's mean fine-tuned values, and subtracts what the cue's mean original values give, since averaging alone gives something back; it reads higher but erases each input's own values, so it cannot be used at every position of a text (report).

What we found. Partly yes, against the per-cue change added to each input; not against its averaged form. On the four tasks with 32 cues, the nearest rule recovers 0.61 to 0.78, about as much as one change per cue added the same way, 0.47 to 0.66 (first figure). Both stay below the per-cue change in E32's averaged form, 0.81 to 1.06 (first figure). About two thirds of the nearest inputs share the cue, against 3% by chance; keeping only those helps where each cue has its own answer (second figure). Groups and the line per piece fall short with many cues (third and fourth figures).

What it means. On one seed, at the trigger, on six toy tasks: the answer is partly yes. Inputs the original Γ treats alike get alike changes, so a rule that names no cue does about as well as the added per-cue form, the form the next test on ordinary text could use. It does not reach the averaged per-cue form on the 32-cue tasks, so it does not replace the per-cue hypothesis. The caveat that set the next test: the nearest rule also lets the change depend on each input's own values, so a match does not show the cue is visible in them; E36 took the rule to a fine-tune with no trigger.

Run
Six do-nothing states from E32 and E33 (" will" then " have", one cue; emoticon, ten cues; copy, where each of 32 key words is followed by itself, and a cipher, where each is followed by a fixed random word, on the same inputs; 32 cue words for " of" trained toward their own answers or all toward " of"), regenerated within 0.0013 of the earlier numbers, one seed, the trigger only; so the four 32-cue tasks are two sets of inputs, each fine-tuned toward two targets. Two RunPod RTX 4090 runs of 58 s and 68 s, about $0.13 plus a share of E36's pod.
Found
  • Naming no cue, the nearest rule recovers about as much as one change per cue added the same way on the 32-cue tasks, 0.05 short on copy and 0.31 ahead where all cues lead to " of"; neither reaches the averaged per-cue form.
  • About two thirds of the nearest inputs share the cue, fewer than the nearly all we expected, and restricting them to it helps only where each cue has its own answer.
  • Surprise: on the one-cue task the nearest rule (0.90) and the line per piece (1.02) beat one shared change (0.71), where we expected no difference; the report reads this as the change depending on each input's own values even with one cue, resting only on these two rules on one seed, with no control run for it (first and fourth figures).
