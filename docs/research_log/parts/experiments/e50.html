Inside the fine-tuned model itself, does any restore number tell a fine-tune that teaches copying from one that teaches a random word map?

2026-10-29 · MATS cluster L40, debug QoS · experiments/restore_anchors

The question. The re-gating line (Q5) asks whether the decomposition can tell an update that strengthens a behaviour the model already has from one that teaches something new. On E12's toy tables, E46's stand-in ratio separates them, about 0.9 for fine-tunes that teach copying against about 0.4 for fine-tunes that teach a random map. But that ratio is read in Γ's stand-in model, a masked model the real fine-tuned model does not contain. Does a number read inside the real fine-tuned model separate the two kinds too?

What we did. E12's four tables each put a key after a marker word. The two copy tables teach the model to repeat the key, meant as "existing"; the two random-map tables teach a fixed common word for each key, meant as "new". Each table was fine-tuned at two seeds, and each update was placed by do-nothing: it sits whole in the residual Δ, leaving the subcomponents (the decomposition's rank-one pieces) and Γ (the frozen network that switches pieces on) untouched. The gain is how far the fine-tune raised the log-odds of the answer at the key position, 13 to 21 nats. Restoring a set means that, at the key position, each of its pieces reads the input it would have had in the original model; the restore share is the part of the gain this takes back, 0 none and 1 all. The sets: every alive piece (the 9,881 that ever switch on); S, the pieces Γ switches on after the fine-tune; D, the same number of pieces per matrix outside S, ranked by pull on the answer (needs the answer, not Γ); and 20 random sets of S's size. The filed rule: the kinds separate if, on each seed, the lowest copy reads at least 0.3 above the highest random map. A follow-up ran hand-made writes that add the answer directly in one layer, to see whether the every-alive share can read low.

What we found. On these eight fine-tunes the kinds do not separate. Restoring every alive piece took back 0.76 to 0.78 of the gain on the copies and 0.66 to 0.73 on the random maps, gaps of 0.03 and 0.05 (figure 1). The hand writes read below zero, so the share is not stuck high; the report reads it as how much of a gain the original weights pass along. S took back under a fifth on both kinds (figure 2). D put every copy above every random map, but by 0.15 and 0.19, and it was filed to be reported only. The original model gives neither kind's answer unprompted (figure 4).

What it means. On these four tables and two seeds nothing filed separates the kinds, and S is closed as evidence of kind under the plan's decision rule, on these four tables and two seeds only; the question of kind itself stays open, which is what the "no answer" chip means. It is "no answer", not "no", because the toys' labels did not hold: the original model does neither behaviour, so these toys cannot show kind in the real model, nor vouch for the stand-in ratio. That ratio, the line's only number that separates the kinds, is untested on a behaviour the original model really performs. What the line does next is a question for you in section {{n:decisions}}.

Run
Eight fine-tunes (four tables, two seeds), read on 97 held-out windows each at the key position: Slurm 43040, L40, 78 seconds, $0. The follow-up (Slurm 43266, L40, 123 seconds, $0) added the hand writes, a split of S and the demonstration probe; all controls read exactly as expected.
