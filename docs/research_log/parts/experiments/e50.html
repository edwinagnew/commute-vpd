In the real fine-tuned model, does putting back the pieces Γ switches on separate a fine-tune of a behaviour the model had from one it lacked?

2026-10-29 · MATS cluster L40, debug QoS · experiments/restore_anchors

The question. Line 1 (Q5). On E12's toy tables the stand-in ratio separates copying (about 0.9) from random maps (about 0.4), but it is read in Γ's stand-in model, which the fine-tuned model does not contain. Does a number read inside the real fine-tuned model separate them too?

What we did. E12's four tables, two copy (repeat the key) and two random-map (give a fixed word for each key), each fine-tuned at two seeds and placed by do-nothing. At the key position we put back the original model's subcomponents on a set of pieces and measured the restore share, the part of the fine-tune's gain (13 to 21 nats) taken back. Sets: every alive subcomponent, Γ's switched-on set, a ranking by pull on the answer, and 20 random sets. The kinds separate if the copies read at least 0.3 above the random maps.

What we found. They do not separate. Every alive subcomponent took back 0.76 to 0.78 of the gain on the copies and 0.66 to 0.73 on the random maps; Γ's set took back 0.14 to 0.19 and 0.10 to 0.20. The filed lean was missed on both kinds' ceilings, and the filed "reversed" reading did not fire. Random sets took back at most 0.11.

What it means. By algebra, restoring every alive subcomponent measures how much of the gain the original weights relay, not whether the behaviour existed, and Γ's set missed its copy floor. Neither number was shown able to read low, so this is untested instruments, not a "No". The separation lives only in the stand-in; what the line does next is a question for you.

Run
Eight fine-tunes (four tables, two seeds), 97 held-out windows each, at the key position; Slurm 43040, L40, 78 seconds, $0. All controls (empty set, restore inside the original model, whole-output reset) read exactly 0.
Found
  • The copies and the random maps took back about the same share, so the gap (0.03 and 0.05) is far under the 0.3 bar.
  • Γ's set took back 2.0 to 2.7 nats on every fine-tune whatever its size, with five pieces in all eight, so it may serve a shared task format.
  • The original model scores the copy answers only 3 to 4 nats above the random ones, so the copy anchor is weak.
