Without a trigger, can each position's re-gating be predicted from how the original model reads it?

2026-10-26 to 2026-10-27 · RunPod RTX 4090, H100 · experiments/regating_spread

The question. Re-gating is the change in Γ's importance values when Γ reads the fine-tuned model instead of the original one, with the pieces themselves unchanged. The re-gating line, Q5, asks whether that change describes the update. In the earlier toy tasks, E18 to E35, a fine-tune taught the model to follow one trigger token with a target token. The change sat at the trigger, and E35 found it follows the inputs the original model treats alike. Real post-training changes text everywhere, with no trigger. This card asks whether the same holds at every position of such a fine-tune.

What we did. We fine-tuned the 67M model on ordinary Pile text that had been lowercased, so capitals never come; no single token cues the change. A first try on code-like text, the 5% of Pile rows richest in code punctuation, learned nothing: its training loss showed no trend and held-out text got slightly worse. The update was left in Δ, the part of the weights outside the pieces (do-nothing), and Γ was kept frozen. Two numbers were read on 64 held-out rows, at every position. The switching share is how much of the fine-tune's gain in log-probability the CI-masked model gets from Γ reading the fine-tuned model; the CI-masked model scales every piece by its importance value and leaves Δ out. A rule's recovery is the rise in the CI-masked model's mean log-probability over all held-out positions it gives, as a share of the rise Γ's own new values give, when each position gets its original values plus the rule's predicted change: 0 means no better than the original values, 1 means as good as Γ's. Rules are fitted on training rows and scored on held-out ones that share no 16-token span with them. The main rule gives a position the mean change of the 8 training positions with the nearest original importance values.

What we found. Switching carries 0.79 to 1.05 of the lowercase fine-tune's gain (first figure). The share is high on the code-like run too, but there it is a share of a gain below zero, so it reads nothing, and a high share alone shows little. The nearest-values rule improves with every fourfold increase in fitted positions and, fitted on all 262,144, recovers 0.76 to 0.89 of the switching (second figure). Nearest by the attention inputs Γ reads does as well, nearest by the last four tokens of text recovers about half, the current token about a third, and position in the row almost nothing (third figure). Each subcomponent's own original value alone recovers at most 0.18 by step 300 (fourth figure).

What it means. On this one fine-tune and seed, the change at a position follows how the original model reads that position more closely than a summary of its last four tokens does. Rules that read each subcomponent's own value alone, and so its room to move, do far worse, so the nearest rule's success needs the values taken together. Three caveats remain. The curve had not flattened. A bag of the whole preceding text scored like rules with no context at all, so whether a better summary of the longer text would close the gap is open. And no rule joining text with each value's room to move was run, so whether the original values beat text for reasons beyond that room is open too. So the restatement "positions the original model treats alike get alike changes" was not established. On 2026-10-27 the user de-prioritised the fixed-shift hypothesis rather than restate it.

Run
A fine-tune of all 24 decomposed matrices on next-token loss, Adam at 3e-5, batches of eight 512-token rows each used once, read at steps 10, 100 and 300 on one seed; the code-like run first, then the lowercase run and six follow-up runs that refitted the rules on more positions or in other spaces. Each run took about 2 min or less on RunPod and cost under $1.
Found
  • Switching carries 0.79 to 1.05 of the lowercase fine-tune's gain, but the code-like fine-tune that learned nothing also gave a high share, of a gain below zero, so the share alone does not show re-weighting.
  • Fitted on 262,144 positions, the 8 nearest positions by original importance values recover 0.76 to 0.89 of the switching on the lowercase fine-tune; the attention inputs Γ reads do as well, the last four tokens about half, the current token about a third.
  • Rules that use each subcomponent's own original value alone recover at most 0.18 by step 300, and a straight line per subcomponent falls to about zero, so the nearest rule's success needs the values taken together.
