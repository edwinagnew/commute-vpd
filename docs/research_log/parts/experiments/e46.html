Does the gain from Γ's new values tell a learned update from one that learned nothing? The re-gating reset, stage 0

2026-10-29 · MATS cluster, debug QoS · experiments/regating_table

Partly. Γ's new values raise the stand-in model's answer by 3.3 to 11.6 nats for every fine-tune that learned, and not for any update that did not; but a random change as disruptive as the fine-tune moves it by up to an eighth of that, and a hand-made write that uses no existing subcomponent reaches 0.16 to 0.34 of the copy fine-tune's value, so neither check retires the line or clears it. Run at $0 in three cluster jobs (Slurm 42604, 42675, 42791).

Run
On seven toy tasks (three single triggers, two copy tables, two random-map tables) and a fine-tune on code text, we computed the gate gain: how far Γ's new values alone raise the stand-in model's log-odds of the answer, with the original subcomponents and Δ out. Beside each fine-tune: a fine-tune to another word, its update with the sign flipped, a random update scaled to the fine-tune's side effects on the full model, and a hand-made write that only points block 1's output at the answer. Nothing run now; the next step waits for you.
Found
  • The control and E12 replicate: the copy fine-tunes keep 0.87 to 0.97 of what the updated subcomponents do unmasked under Γ's new values, the random maps 0.36 to 0.41, within 0.002 of E12; every update that does not raise the answer gives a gate gain of zero or below, down to −4.8 nats.
  • A random change as disruptive as the fine-tune gives a gate gain of −0.17 to +0.48 nats, at most an eighth of the fine-tune's on the same task, and about what the change does to the real model's answer (0.79 to 1.21 times it where that is over 0.1 nats), so this check is inconclusive: the gain follows how much a change moves the answer, not whether it was learned.
  • The hand-made write earns 1.8 and 3.9 nats on the two random-map tables, 0.16 and 0.34 of the copy fine-tune's gate gain (it passes the 0.5 line, thinly) but half to two-thirds of the random-map fine-tunes' own, so a write with no existing machinery sits close to a new behaviour.
