Does the gain from Γ's new values tell a fine-tune that learned something from a change that learned nothing?

2026-10-29 · MATS cluster, debug QoS · experiments/regating_table

The question. The re-gating line asks whether the new importance values the frozen Γ gives after a fine-tune describe how the model changed (Q5). They might instead be an after-effect of Γ reading a model it was not trained on. A red-team review showed that the line's old headline share read about the same for an update that learned nothing. So the line was reset. Its stage 0 asks whether any number built from Γ's new values survives changes that, by construction, taught nothing.

What we did. Γ is the decomposition's importance function: at each position it says how far each rank-one piece of the 67M model's weights is switched on. The stand-in is the model rebuilt from the original pieces alone, each scaled by Γ's value, without Δ, the part of the weights the pieces do not cover. The real model is the full changed weights, Δ included. The gate gain is how far the stand-in's log-odds of the answer rise, in nats, when only Γ's values come from the changed model. We read it on toy fine-tunes, two seeds each, and beside each on up to four nulls. One, on the three single-trigger tasks, is a fine-tune to another word, ` http`, which lowers the answer. One is the fine-tune's change with its sign flipped. One is a random change, scaled until it disturbs the model's other predictions as much as the fine-tune does. The last is a hand-made write: one matrix in block 1 changed so each key points at its answer, with no training.

What we found. Every fine-tune that learned raises the gate gain by 3.3 to 11.6 nats. The changes that lower the answer read below zero, and the random changes stay within half a nat of zero (first figure). The random change reads at most an eighth of the fine-tune's value, but sits outside the noise floor on six of seven tasks, so its test is inconclusive (second figure). Its gate gain roughly equals what it does to the real model's answer (third figure). The hand-made write passes its test against the copy fine-tune, yet earns half to two-thirds of the random-map fine-tune's value (fourth figure).

What it means. On these toys a random change's gate gain follows how much it moves the real model's answer, so at small sizes the gate gain alone does not show whether a change was learned; the fine-tunes stand apart by size. Neither null retires the line or clears it. A follow-up read stage 1's planned number, the stand-in ratio, on the nulls; it turned out to be nearly the gate gain over the pieces' own gain, and adds little (fifth figure). The project did not carry that ratio to Qwen as planned; E50 read the real fine-tuned model on the same tables next.

Run
Seven toy tasks on the 67M model and one code-text fine-tune, each fine-tune read beside its nulls; a follow-up then split the writes and random changes as the fine-tunes had been. Four debug jobs on the MATS cluster at $0: Slurm 42604, 42675, 42791 and 42993.
Found
  • The apparatus reproduces E12, an earlier run on the same four tables: the stand-in ratio reads 0.87 to 0.97 for the copy fine-tunes and 0.36 to 0.41 for the random maps, as expected.
  • A random change as disruptive as the fine-tune gives up to an eighth of its gate gain, about what it does to the real model's answer where that exceeds 0.1 nats; on one random direction per task that check is inconclusive.
  • The hand-made write passes against the copy fine-tune but sits close to the random-map fine-tunes, on the gate gain and on the stand-in ratio, which is mostly the gate gain.
