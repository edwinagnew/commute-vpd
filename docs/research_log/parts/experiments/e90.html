Can the definition of existing and new be applied to the old 67M tasks?

2026-11-05 · CPU only so far, $0 · experiments/new_vs_reuse · provisional, not independently checked

The question. The "existing" and "new" labels the old 67M experiments assumed were never measured against the definition in section {{n:overview}}. If the definition cannot read them, findings that depend on those labels are weaker than the log says.

What we did. We froze the definition (it stays as written, with the admissibility rule accepted today) and filed, before reading any task, what each rule should say on 29 task and capability pairs and on a set of edge cases. Stage 0 ran on the text of the tasks with no model, and checked each pair against the rule.

What we found. The rule behaved as filed on every case but one: the elicitation task with the original model's guess as the capability was filed "not admissible" and read admissible on one key (1158), where the value equals the guess, 1 of 12 against a floor of 0. The filed prediction stands and this is reported as a gap in the rule's wording, not corrected.

What it means. The definition is frozen and no result from the 67M changes it until the 67M table and a one-page Qwen check are both in; changes are then proposed to you in one batch. The definition is silent on the emoticon, ladder, many-cues and lowercase tasks, and says so wherever it is stated. Nothing here reads a fine-tuned state yet.

Run
Stage 0 on CPU, no model, minutes, $0. A Qwen check on paper, no run: which capability each of the three Qwen example updates could be running through. Input-dependent versions of the ladder, emoticon and lowercase tasks are coded and not run, and so is Amendment 1 (below); a stage-1 job on the cluster (52317) read the old control that Amendment 1 replaces.
Found
  • The admissibility rule matches its filed cases, with the one elicitation miss above.
  • Tasks whose answer is the same for every input read "definition does not apply" for every capability.
  • On Qwen the definition writes only for the answer-format template, with no spared control; for the TOFU facts it is silent rather than "new", and for reinforcement learning it cannot be written for either seed, both failing before the admissibility rule is reached.
