Once both fine-tunes have learned their sentences, do the carrying neurons separate an update that confirms the model from one that contradicts it?

2026-11-06 · provisional · two cluster debug jobs (54053, 54062), $0 · experiments/larger_size

The question. E107 found that at the small matched update size the carrying neurons (the neurons that carry a fine-tune's update) do not tell wrong answers from true ones, but the wrong-answer run had barely learned its answers. Does the set separate them once both runs have learned their sentences?

What we did. We fine-tuned Qwen3-1.7B for five epochs on 217 true answers about real people and world facts, and separately on wrong answers to the same questions, two shuffling seeds each. We took each run's 1,024 carrying neurons (of 172,032) and measured the overlap of the sets: two reruns of one run (the seed level), the wrong run against the true run, and the true run against an unrelated fictional-author run. The test only reads if the seed level stands clear of the unrelated overlap by more than its own noise. No decomposition is read: this is the neuron baseline.

What we found. Both wrong-answer runs learned their answers (they prefer the wrong sentence in 217 and 216 of 217 rows). But two true-answer reruns share only 0.65 of their set on fictional-author text and 0.62 on the answer tokens, against 0.90 and 0.88 at the small size, and the unrelated run sits at 0.51 and 0.49. That is too little room, so the test has no power and makes no call on either probe; the filed lean was that it would have power.

What it means. At the size where the facts are learned, this neuron ranking cannot tell wrong facts from true ones, and at the size where it was stable the facts were not learned, so the neuron baseline has no known-against-new reading for this pair. Set beside VPD's readings on the same fine-tunes (second figure), neither method tells new from existing on Qwen: at matched size VPD separates the layout fine-tune from invented facts and neurons do not, but a known-facts fine-tune reads on the invented side; neurons separate known from invented facts, VPD only as description; wrong answers stay beside true ones, pointing to topic or style; and at the learned size neither reads these pairs. Provisional: two seeds per run; the table's check holds with a caveat, E109 has none. You chose to go on in order: the table (done), a stable ranking at the learned size, then new invented facts.

Run
Two $0 cluster debug jobs on one L40: the control first (stage 0 reproduced every stored number), then both wrong-answer runs trained to the end and read.
Found
The wrong-answer run learned its answers, as expected. The seed level fell to 0.65 and 0.62, under the line of about 0.75, where we expected power. The wrong run's set sits inside the true run's at 0.66 to 0.69 and 0.55 to 0.60, level with the seed level, which is not a reading of the label.
Bears on
The claim that cheap instruments without a decomposition tell reuse from new learning: no neuron reading separates them, and this one has no power at the learned size. Beside VPD's readings neither method tells new from existing on Qwen.
