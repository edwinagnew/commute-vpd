Before any update, is the decomposition already too far from the original model at the cipher's cue for a cue-based pass to judge a map?

2026-10-29 · MATS cluster L40 · experiments/pass_reread

The question. E42 copied a word-cipher fine-tune into the decomposition by teacher training. The copy passed the adversarial check on ordinary text, but its masked model lost the cipher at the cue. The masked model is the model rebuilt with each subcomponent scaled by the importance Γ gives it. So on 2026-10-29 the user chose to add a second part to the pass (Q4): the masked model must also keep the behaviour on the task's own text. The same decision said to check the unchanged decomposition first. Every map starts from the unchanged decomposition and the same Γ. If its own masked model is already far from the original model at the cue, the new part would mark every map as failing because of the decomposition, not the map.

What we did. We took the original model and its unchanged decomposition, with no update at all. Δ, the part of the weights the subcomponents do not cover, stayed at its original value. In E10's word ciphers each window holds a marker never seen in ordinary text, then a key word; the cue is the next position, where the model must give the key's value. With 32 random pairs, each of 32 keys maps to an arbitrary word; with one random pair, there is a single key. The identity control is the same 32 keys on the same windows, each key followed by itself. In this run it is not a separate measurement: the distance never reads which word follows the key, so it must read the 32-pair value, and it checks only the bookkeeping (report). We measured how far the masked model is from the original model at the cue (KL, averaged over 97 held-out windows). We divided it by the same distance on ordinary text, 256 Pile rows. A ratio of 1 means the masked model is as close at the cue as on ordinary text. The stop line was 1.5. That is the project's fixed line for the adversarial ratio, where a map that does 1.5 times the unchanged decomposition's damage fails. Here it is applied to the unchanged decomposition itself. At 1.5 or more on either random cipher, the new part would not be used. The cues of four earlier tasks are printed beside for reference: emoticon → o, the rare target " in" → " Fig", and the first two rungs of the task ladder.

What we found. At the cue, the masked model is 1.86 times its ordinary-text distance on 32 random pairs and 2.21 times on one pair, both past the line (first figure). The earlier tasks' cues read 0.76 to 1.48, emoticon closest to the line. In absolute terms, the masked model starts 0.65 to 0.77 nats from the original at the cipher's cue, and putting Δ back moves that by about 0.001 (second figure). A separate follow-up question, which does not bear on the stop decision, asked how many subcomponents carry each teacher-trained cipher copy's gain: it spreads its gain over about a thousand subcomponents or more (third figure).

What it means. No map was tested. The run measured only the floor any map starts from, and the decomposition already sits past the line there. The report weighs this against scale: the gap is about 0.65 nats, while E42's fine-tunes move the cue by 10 to 13, so the new share would have had room to separate copies. It falls back anyway because that share is measured against the unchanged decomposition's masked model, and a reference already twice as far off as on ordinary text would not read the map alone (report). The 1.5 line is borrowed from the adversarial check and fixed before the run; the plan itself said this branch rests largely on that threshold (report). The pass for the weak version therefore stays reading A, the adversarial check on ordinary text, with the cue reading printed beside each verdict but not deciding it. If a later decomposition reads under 1.5 at its own task's cue, the new part becomes usable. The Qwen line, whose plan uses the same reading, should check its unchanged model the same way first (report).

Run
One job (Slurm 42757, 2 minutes, $0) read the unchanged decomposition's masked model at six tasks' cues and on ordinary text, after two apparatus checks passed: the masked forward reproduced the harness's ordinary-text number, and with every mask at 1 it reproduced the original model. A second job (Slurm 42960, $0) undid E42's three cipher copies one subcomponent at a time.
Found
  • Before any update, the masked model is 1.86 and 2.21 times its ordinary-text distance at the two random ciphers' cue, past the 1.5 line, on one decomposition; we had expected this, with medium-low confidence.
  • Putting Δ back at its original value moved the cipher-cue distance by about 0.001 nats, so the choice of Δ convention did not matter.
  • On one copy per cipher task, half the gain at the cue needs about 1,900 and 1,100 of the 9,881 alive subcomponents on the two random ciphers, and about 990 on the identity control, far more than the tens we expected. The repair is not a small change to which subcomponents Γ switches on, and this count does not tell a new behaviour from an old one (report).
