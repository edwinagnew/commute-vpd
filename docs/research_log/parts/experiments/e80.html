Qwen3-1.7B: does VPD's adversary fail doing nothing, and does it pass a good placement?

2026-11-04 · RunPod H100 PCIe, 1.94 h, $6.21 billed · experiments/qwen_d1_adversary · one update, one start per state but the original model; independent check done

The question. D1 is a map on Qwen3-1.7B that keeps the decomposition faithful for a real update, judged by a test that can fail a bad placement (Q1). E79 showed the state's own-mask read cannot be that test, since doing nothing reads as well as the best trained change. Does VPD's own adversary, which searches for the masks that hurt a state most, do better?

What we did. We ran the adversary (20 sign steps up the KL from a random start, one setting per subcomponent shared by all rows) on 64 maths rows, on the original model at two starts, on doing nothing (the fine-tuned weights with the whole update left in Δ), on the in-span placement (the least-squares split's change to the subcomponents) and on the clean-term change. The ratio is a state's read over the original model's at the first start, and the bars are the ones filed in E71: doing nothing fails above 1.19, a placement passes at 1.40 or below.

What we found. The filed outcome is "D1 has a test and a first candidate": doing nothing reads 1.317, over its fail bar, and in-span reads 1.197, under its pass bar. That reverses the filed medium lean that doing nothing would read within the band. The outcome reads better than the numbers: doing nothing's 1.317 is itself under the in-span pass bar of 1.40, the states differ by about 10% where the original model's two starts differ by 16%, and the independent check found the ratio on the maths rows already there before the attack (1.34 to 1.44 at step 0), while on web text doing nothing starts at 1.005 and the attack raises it to 1.28.

What it means. The adversary reads doing nothing above the original model, but no placement has been shown good, and the run does not rank doing nothing, the clean-term change and in-span. We claim no cause for doing nothing's rise. The next run reads in-span and the clean-term change on the web-text rows, where the attack itself shows the rise, with paired starts.

Run
One RunPod H100 PCIe for 1.94 h at $6.21 billed: maths rows 64-127 at 256 tokens for the five reads, web-text rows (128 at 512 tokens) for the original model and doing nothing only. The control, the original model on web text, read 1.75 against the earlier job's 1.70.
Found
  • Doing nothing reads 1.317 times the original model on maths rows and 1.28 on web text; in-span reads 1.197 and the clean-term change 1.253, so the filed outcome stands and the medium lean was wrong.
  • The filed bars do not cohere: doing nothing is under the in-span pass bar, the clean-term change passes with a weight error (1.36) worse than doing nothing's (1), and in-span is over doing nothing's fail bar by 0.007.
  • On maths rows the ratio exists before the attack (1.34 to 1.44 at step 0, random sources), so a fail there is not the adversary finding the update in Δ; no cause is claimed.
