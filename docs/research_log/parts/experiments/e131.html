Is Goodfire's new Qwen3-1.7B decomposition more faithful on reasoning text than the old one?

2026-11-07 · cluster debug L40, jobs 55508-55542, about 5 hours of card in all, $0 · experiments/qwen_new_decomp · provisional, one adversary start, not independently checked

The question. Every Qwen reading so far rests on one decomposition of Qwen3-1.7B (run p-e9fcffd5, "the old decomposition"). Goodfire released a second (run p-9707d6ff, "the new decomposition"), trained on chat text that includes Qwen's own answers and said to be more faithful on reasoning. Our fine-tunes are on GSM8K maths, so the choice of decomposition matters for every later reading.

What we did. We ported the new decomposition into our code and checked it against the authors' library, then read both decompositions on the same 128 rows of each of three kinds of text: web text, and GSM8K answers written by Qwen itself with thinking off and with thinking on. Two faithfulness numbers per row, each the KL divergence (in nats; 0 means the masked model predicts exactly like the model) from the model to the decomposed model: with the decomposition's own masks, and with the masks moved by VPD's adversary (one random start, 20 steps). A bigger number means easier to break. A ratio under 1 means the new decomposition is the more faithful.

What we found. Under the adversary the new decomposition reads 0.14 and 0.15 of the old one's KL on maths (11.4 to 1.6 with thinking off, 6.6 to 1.0 with thinking on), lower on all 256 rows, and 0.75 on web text. With its own masks it reads 1.07 of the old on maths with thinking off (the filed prediction missed), 0.88 with thinking on, and 1.48 on web text. It switches on 26 to 30% fewer subcomponents per token.

What it means. On the text our updates are on, the old decomposition is four to seven times easier to break than on web text and the new one is not, so the new one looks the better base for GSM8K readings, with its own masks about equal on maths. It is provisional: one adversary start, 128 rows from the first GSM8K test prompts, no task accuracy under the masks. The user is asked whether the faithful-map work on Qwen should move to it.

Run
Port checks first (all passed: the new subcomponents rebuild all 196 matrices to 0.0055 relative error, our importance function agrees with the JAX library on all but 1.2e-5 of values), then six measurement jobs, one per decomposition and row set, each 26 to 39 minutes on a MATS debug L40, $0.
Found
  • The adversary gap on maths is large and consistent: new over old 0.141 [0.135, 0.146] with thinking off and 0.153 [0.149, 0.157] with thinking on.
  • With its own masks the new decomposition is not clearly better: 0.061 against 0.057 nats on maths with thinking off (the filed prediction missed), 0.053 against 0.060 with thinking on, and worse on web text (0.209 against 0.142).
  • Three of the four filed predictions held (both adversary rows, own masks with thinking on); every number is one adversary start on 128 rows.
