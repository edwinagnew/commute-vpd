Does re-gating follow whether the model's existing copying mechanism carries a new fine-tune, or only whether the answer was already likely?

2026-11-02 · MATS cluster L40 debug QoS, $0 (job 48507) · experiments/induction_cue

The question. You decided on 2026-11-02 that "elicitation" means the fine-tuned behaviour runs through a mechanism the original model already has, so re-gating's share r is a candidate to score against a causal check, not the definition (Q5). On the small model r follows how likely the original model already was to give the answer (E58), which cannot tell the two apart. This is the first test where "old mechanism" and "answer already given" come apart.

What we will do. The small model already copies in context: after "A B ... A" it says B. We teach it to copy at a new marker, where it does not copy yet, and beside that teach a lookup at the same marker on the same text. We switch off the heads the model copies with: the copy fine-tune should lose most of what it learned and the lookup little. Then we read r on both. If r follows that label, it reads the mechanism where the prior cannot; if both read low, it reads the prior.

What we found. The code is written and its predictions filed, and the first job stopped in its checks at $0 with nothing trained. One head carries the copying: switching it off takes copying from 0.82 to 0.01. At the new marker the original model already gives the copied answer at probability 4.3e-4, 5 times more than with the pair broken, and no word among the 128 candidates for the lookup is that likely, so the two fine-tunes could not be matched on the answer's prior.

What it means. The copying route already fires weakly at the marker, so the cell reads "old mechanism, answer weakly present", which is still the test wanted. On Fable's advice an amendment now draws the lookup's words from tokens of any frequency, per key and kept out of that key's own windows, and adds two reading cells for r (both high with no gap, and a reversed label); no filed bar moved. It is coded and filed, not run.
