Does re-gating follow whether the model's existing copying mechanism carries a new fine-tune, or only whether the answer was already likely?

2026-11-02 · MATS cluster L40 debug QoS, $0 (job 48507) · experiments/induction_cue

The question. You decided on 2026-11-02 that "elicitation" means the fine-tuned behaviour runs through a mechanism the original model already has, so re-gating's share r is a candidate to score against a causal check, not the definition (Q5). On the small model r follows how likely the original model already was to give the answer (E58), which cannot tell the two apart. This is the first test where "old mechanism" and "answer already given" come apart.

What we did. The small model already copies in context: after "A B ... A" it says B. We teach it to copy at a new marker, where it does not copy yet, and beside that teach a lookup at the same marker on the same text. We switch off the heads the model copies with: the copy fine-tune should lose most of what it learned and the lookup little. Then we read r on both. If r follows that label, it reads the mechanism where the prior cannot; if both read low, it reads the prior.

What we found. With the copying head off, the copy map lost 0.56, 0.55 and 0.47 of its gain (bar 0.5) and the lookup nothing, so the filed verdict reads copy_not_elicitation while the numbers say "about half", and r was not scored because one seed fell short of the bar. Provisional and unscored: at lookup words whose prior is within a factor 1.3 of the copy map's, r reads about 1.09 and 0.40, so the prior alone does not set r; but the copy map's target is also in its context, so that gap is not credited to the mechanism.

What it means. The fine-tune partly reuses an old mechanism, and r's high reading on it cannot be credited to that mechanism. The granularity limit stands: a new circuit built from old pieces reads as elicited. An independent check recomputed every number and agreed that r is not scored; it also found that update size separates the two maps as cleanly as r does and that "the prior account fails" needs "unscored" and its limits, so the report's wording is being corrected. Nothing further is proposed.
