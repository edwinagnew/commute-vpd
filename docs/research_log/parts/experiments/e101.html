Do the neurons that carry a fine-tune have an original job on the Pile that names the task?

2026-11-05 · cluster L40 debug, $0 · experiments/carrying_jobs · provisional, not independently checked

The question. If a fine-tune built to reuse an ability is carried by neurons whose old job already relates to the task, and one built to teach something new is not, then a neuron's job is a reuse reader that needs no decomposition. E98 found which neurons of the original model carry each of 43 saved fine-tunes of the 67M; this asks what those neurons did before training, read the way the "already clean" essay reads neurons.

What we did. For each carrying neuron we wrote a one-line job from the Pile windows where it fires hardest, and asked a judge whether that job relates to the task. The same was done for a random partner neuron matched by layer (the floor), and for the ten neurons of the original model that fire hardest at each task's answer on three tasks (the positive control, which the method should tie to the task if it can tie anything).

What we found. Almost no carrying neuron's job was tied to its task, for tasks built to reuse and tasks built to be new alike (lowercase 0 of 16, against a floor of 1 of 179). The positive control read 0 of 10 on all three tasks. The jobs do drive their neurons, but near misses fire them too (for random neurons 0.44 of near misses fire strongly, against the essay's 0.11).

What it means. On the 67M this reading has no power to label a fine-tune as reuse or new, so GOALS.md gets no answer from it either way. Amendment 1 (a judge that sees each task's windows, with task-specific controls) is coded next.

Run
Cluster L40 jobs 52876 and 52885 in debug, $0, with 36 agent calls (writer, maximiser, judge). Stage 0 measured each set's engaged share first.
Found
  • The judge tied almost none of the carrying neurons' Pile jobs to their task, on built-to-reuse and built-to-be-new tasks alike.
  • The positive control failed: the original model's top firers at each task's answer were never judged related.
  • So the essay-style job reading has no power on this model, and the reuse-against-new rows were not read.
