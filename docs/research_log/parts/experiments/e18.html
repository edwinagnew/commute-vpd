Mechanism or leak: does one shared switch pattern carry the switching effect?

2026-10-21 · MATS cluster L40 · experiments/regating_leak

Mostly a mechanism, but the filed test did not show it on the two word tasks. After a fine-tune whose update sits in Δ, Γ reading the updated model switches existing subcomponents on and much of the behaviour returns. One fixed pattern of importance values at the trigger, the same for every input, gives most of that back on all three tasks, and random or wrong-target patterns give none (first figure). The filed pattern, each input's original values plus one shared change, cleared its bar only on emoticon (second figure). An amendment found why: mostly because it keeps each input's own original values, a fifth to a third the clip, none the dead subcomponents, and no pattern in it reads the updated model's values for the input (fifth figure). The user did not back that as a mechanism: it is the leading hypothesis, H, in three parts, to be tested harder. Two amendments tested each part. The change is the same for every input and needs its own subcomponents, but the filed claim that it is enough on its own failed (seventh figure). A fourth amendment found the leftover that failed it is mostly what any averaged pattern recovers, with 0.01 to 0.05 of the effect input-specific. The user now holds a restated H as a working hypothesis, not a finding: one fixed change carries most of the switching effect, and inputs' own variation adds a few hundredths.

Run
Do-nothing states of three Adam fine-tunes, ten steps, two seeds each: emoticon, " which" then " was", " we" then " just". At the trigger only, Γ's values replaced by a test pattern: each input's own updated values, the original values plus one shared change per matrix clipped to 0 to 1 (the filed test), the updated model's mean values, a different target's shared change, and the shared change moved to random subcomponents, twenty draws. Read on 73 to 106 held-out windows per task. Also the switched-on set's overlap with the original model's subcomponents for the token on Pile. Job 28204, 139 s, $0.
