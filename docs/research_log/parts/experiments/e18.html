E18mixed

Does one fixed change to Γ's importance values, the same for every input, carry the switching effect?

2026-10-21 to 2026-10-22 · MATS cluster L40 · experiments/regating_leak

The question. On the re-gating line (Q5), a fine-tune's weight change is left in the residual Δ: the do-nothing placement. The frozen importance function Γ then reads the updated model and switches on subcomponents it kept off before. The original subcomponents under Γ's new values give back much of the fine-tune's gain on the target. Call that the switching effect: the rise in the target's log-odds at the trigger when Γ reads the updated model instead of the original, with the subcomponents unchanged. Either the update switches on a fixed, reusable set of existing subcomponents: the mechanism reading. Or Γ's values, each computed from the updated model, smuggle each input's own information into the forward pass: the leak reading. Under a leak, re-gating would describe how Γ is wired, not the update.

What we did. Three tasks, each a ten-step fine-tune with two seeds: after the emoticon :) predict o, after which predict was, and after we predict just. At the trigger only, we replaced Γ's values with a test pattern. Every number on this card is a share: what the pattern gives back of the switching effect, divided by what each input's own updated values give back (those recover 0.86 to 0.99 of it). So 0 is the original model's values, 1 is each input's own updated values, and a share below 0 means the pattern lowers the target. The fixed change is one set of value changes, the same for every input: the average, over training inputs, of updated minus original values. The test written beforehand added the fixed change to each input's original values; 0.7 or more would support the mechanism reading, 0.3 or less a leak. Two other patterns are not the fixed change. The average pattern gives every input the updated model's average values; another input's values gives each input a different input's updated values. After the first follow-up the user restated the mechanism reading in three parts, each tested by later follow-ups: the fixed change is (a) the same for every input, (b) tied to the subcomponents that receive it, and (c) enough on its own.

What we found. The test written beforehand passed on emoticon only: the fixed change added to each input's original values gave back 0.72 to 0.73 there, and 0.40 and 0.62 on the word tasks, between the two lines (first figure). The average pattern and another input's values give back most of the effect on all three tasks. Parts (a) and (b) held: another input's values give back 0.89 to 1.00, and the fixed change shuffled among subcomponents gives back nothing (first and second figures). Part (c) failed as filed: with the fixed change removed, each input's values still give back 0.16 to 0.31, above the bar of 0.15. But another input's leftover gives back nearly as much, so only 0.01 to 0.05 of the effect depends on the input itself, on two seeds with no noise floor measured (third figure).

What it means. On these three tasks, two seeds each, the switching effect looks mostly like a fixed, task-specific change at the trigger rather than a leak. That reading rests on the average pattern and another input's values, not on the test written beforehand, which passed on emoticon only. The leftover is not empty. On 2026-10-22 the user adopted the reading as a working hypothesis, not a finding: the fixed-shift hypothesis. One fixed shift to Γ's values at the trigger carries most of the switching effect; each input's own variation adds a few hundredths. Later runs tested its scope on more tasks.

Run
Do-nothing placements of three ten-step Adam fine-tunes, two seeds each, read at the trigger on 73 to 106 held-out inputs per task; the switching share matched earlier runs to 0.001. Five MATS cluster jobs from 28204 to 29210, each under three minutes, $0.
Found
  • The test written beforehand, the fixed change added to each input's original values, passed on emoticon only (0.72 to 0.73) and fell between the lines on the two word tasks; the average pattern and another input's values give back most of the effect on all three.
  • The fixed change works only on its own subcomponents, and, unexpectedly, the ones it turns down matter about as much as the ones it switches on.
  • The fixed change is not enough on its own as filed, but only a few hundredths of the effect depend on the input, with no noise floor measured; away from any trigger it raises the target on emoticon only (report, no figure).
