Qwen3-1.7B: does reinforcement learning on maths problems gain more than the same loop with shuffled rewards?

2026-11-03 · rehearsed on the MATS cluster L40 ($0, jobs 50067-50266); paid run on one H100 approved by you on 2026-11-03, $33 · experiments/qwen_rl · independent check done, no bug found

The question. The Qwen deliverable D2 asks for the same table for a supervised fine-tune and a reinforcement-learning update of the same model, and no reinforcement-learning update of Qwen3-1.7B existed. This run makes the first one, and a control that shows what the training loop does when the rewards carry no signal, so that qwen-decomp-lead can map and test them.

What we did. We trained the unchanged model on GSM8K school-maths problems three ways, 100 steps each, with 64 problems and 8 sampled answers per problem at a learning rate of 1e-6: reinforcement learning that rewards right answers (GRPO), the same loop with the rewards shuffled within each problem (the null, which should learn nothing), and supervised fine-tuning on the model's own correct answers. Each arm is one seed. We then scored all three on the same held-out problems, from GSM8K's test set and from GSM1K, with a strict grader (the answer must be in the exact format the reward wants) and a lenient one (format ignored). The change in the 196 decomposed weight matrices is saved at steps 1, 2, 5, 10, 20, 50 and 100; nothing here applies a map or reads the decomposition.

What we found. Under the strict grader, RL beat the shuffled-reward run by 3.2 and 3.1 points on the answers all three states finish (standard error about 1, over problems, with weights fixed); the lead is 3 to 8 points depending on how long answers are counted. With format ignored on those answers the lead is +1.2 and +0.7, not separable from zero, and accepting forms like "So the answer is 20" takes the strict lead to +1.25 and +0.81. So the firm lead may be largely answer format, and better maths is not shown. The null gained 5.6 points on the test set against a filed limit of 1.5, and the cause is open; its lower share of finished answers cancels most of its gain when answers running past the window count. Fine-tuning on its own correct answers gains 2.6 and moves the model far less (KL 0.0017 against 0.194 for RL).

What it means. RL's gains of 9.0 and 7.1 points overstate what the reward added, since format is part of them and the null gained too: we cannot say RL does better maths than this null, or that the lead holds against shuffled-reward runs in general. The shuffled run is a large change in behaviour without signal, not a do-nothing. The saved updates go to qwen-decomp-lead for the table (E75). A second seed (2026-11-04) reversed our lean: RL minus the null on the same problems is +6.4 (standard error 1.1) under both the strict and the format-relaxed grader, since both arms now write the filed answer form; the null gained +1.6 against seed 1's +5.6. Analysis of it is pending.
