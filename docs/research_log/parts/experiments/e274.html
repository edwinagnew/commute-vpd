Does a one-gain squared-cosine share read reuse the way the definition asks?

2026-11-23 · cell P1.55, definition-lead, red-team: not a reading of reuse · experiments/cos_admissible

The question. The write-share reading has a rival, the squared cosine between a part's write in the fine-tune and in the base model. The admissibility page of 2026-11-22 found three faults in the old version (the gain varied from input to input, its sign was ignored, and it pooled inputs from the base model's runs). Once fixed, is it admissible, meaning it reaches its top exactly when every needed part is kept, and does it track reuse?

What we did. From the saved sums behind the write share, with no new forward pass, we rebuilt it with one positive gain per part across every input the fine-tune sees. A part's value is 1 when its write is exactly a positive multiple of the base model's, and 0 when the best gain is zero; a state's reading is the mean over the needed parts that changed. We read it on the 73 saved states, beside the write share. Hand-built cases and exact gains of 0.5, 2 and 10 read 1 to within 6.7e-16.

What we found. It is admissible on all 73 states: only the collapsed state with an empty needed set reads 1, and both gain edits read below it (0.945 and 0.347), as filed. But the 65 trained and random states all read between 0.9935 and 0.9999, its rank correlation with the write share is -0.58, and gain x10 reads lowest of all 73, below every random edit. The filed count of per-part disagreements with the reference was missed as filed (60 parts, not 0); all 60 were changes of pure rounding in the reference, and none remain once rounding counts as no change.

What it means. Per part, one minus the squared cosine equals one minus the part's write share times the size of its change. A fine-tune changes each part a little, so the shortfall is squeezed toward 0 whether or not the change is a gain (rank correlation with change size 0.92). The share is admissible but measures how much each part changed, so it is not a reading of reuse; the write share stays the reading.

Run
CPU only, seconds, $0, from saved files on the 73 states; one run of one allowed.
Found
  • Admissible on all 73 states, and both gain edits read below the top, as filed.
  • Trained states cluster near 1 (0.9935 to 0.9999) and gain x10 reads lowest (0.347), against 0.945 for gain x2, because the squared cosine counts every part once.
  • The 60 per-part disagreements missed as filed came from rounding in the reference; the cause was found.
