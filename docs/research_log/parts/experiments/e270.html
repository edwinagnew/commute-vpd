Does the write share E_b tell Qwen3-1.7B's fine-tunes from random changes, and real learning from collapse?

2026-11-22 · cell P3.14, qwen-lead, no independent check · experiments/qwen_eb

The question. You adopted the write share E_b as the reading of reuse: of the change in what each subcomponent writes, the fraction that lies along what it already wrote. It was built and tested on the 67M model. You allowed one extra Qwen run, if it went somewhere: does E_b on Qwen3-1.7B's saved fine-tunes sit above a random change of the same size, and does it tell a real RL run from one that collapsed?

What we did. On the new decomposition (p-9707d6ff, all 196 matrices) and 64 maths rows we read E_b for six saved step-75 updates: RL, RL on shuffled rewards (which collapsed), and supervised training on the model's own samples, two seeds each. Each was read beside one Gaussian change with the same norm in every matrix. The controls ran first: do-nothing reads 1, and doubling 32 chosen subcomponents per matrix reads 0.83 against a bar of 0.5.

What we found. The updates read 0.112 to 0.157 and their random changes 0.012 to 0.057, so every gap is positive (0.055 to 0.131). The collapsed run reads as high as real RL (gaps 0.123 and 0.116 against 0.091 and 0.131). The random change varies from draw to draw, so one draw is a noisy reference.

What it means. On Qwen E_b separates a trained update from a random one, but not learning from collapse, and it gives no reused-against-new verdict. All updates sit far below the doubling control, so most of each change is not a rescaling of existing writes. The pair library was not run, since its sides are not yet fit to read.
