The question. "Half-known" rests on the original model's output ranks, the same thing the maps were built on (E54). E59 tried a decomposition-free label with a readout over all 50,277 tokens and it memorised its training text (Q5). The user approved a smaller one on 2026-11-02, as the causal check that "elicitation" now asks for.

What we will do. Fit, on Pile text, a readout from each block's activations to only the pair's 64 table values, with a guard that it is specific to the keys. Then remove its direction from each of the 12 saved fine-tunes and compare how much of the gain goes for the elicit fine-tunes and for the ciphers. First, a $0 check of the original model's own per-window ranks, which E59 never measured. Because that check showed the model itself misses E59's absolute bar (16 of 32 keys in the band where 24 were needed), "possessed" is now relative to the model's own possessed set: a block counts if it holds three quarters of what the model holds. Stage 0 stops if the model holds fewer than 8 keys, and two elicit values with too few Pile positions to fit are left out.

What it means.
