Does the reuse member of each trained pair keep more of its neurons' rules than its twin?

2026-11-18 · cell P1.25, run 2 of 2, no independent check · experiments/rule_retention_pairs

The question. Part 2 is testing causal-rule retention at the level of single MLP neurons, a candidate wording of "reused against new" that is not adopted (section {{n:next}}, cell P1.25). Run 1 (E195) calibrated it on built items. Here it reads the five pairs of fine-tunes built so that one member reuses a skill the model has and its twin must learn something new. Does the reuse member read higher?

What we did. We read all twenty fine-tunes of the five pairs, on seeds 0 and 1, with run 1's fixed choices: the retention is the mean rule similarity over a smallest set of changed neurons that recovers 0.9 of the next-token change, averaged over five search orders, with 1 meaning every rule kept. The user filed one descriptive rule with no bar: in each counted pair and seed the reuse member reads strictly above its twin. Four pairs count (copy against cipher, identity against random key table, real case labels against a case twin, real repeats against a repeat twin); the parity twin against a memorised fact is reported and not counted. Every pod's do-nothing control read "no change".

What we found. The filed rule holds in all 8 counted pair-seeds. The margins are tiny: every fine-tune reads 0.996 or more, and the gaps run from 0.00004 to 0.0028, the largest (case) about a tenth of run 1's 0.03. The gaps rank the pairs exactly as the twins' larger MLP updates do (twin over reuse member: 2.5 to 2.7 times for case, 1.4 to 1.6 for repeat, 1.05 to 1.13 for the key tables), and the memorised-fact pair, whose sides moved their MLP weights equally, reads a tie.

What it means. The neuron-level reading points the right way on every pair, but this run cannot tell retained rules from a smaller update, since the score falls as the update grows; separating them needs pairs matched in update size, not run. Level A also scores only the part of each change that neurons carry, and attention carries more of the reuse members' change. No fine-tune is called reuse or new here.

Run
Five RunPod pods, one per pair, twenty fine-tunes read on 512 held-out windows each; controls first, and each fine-tune's gap from the original model matched the earlier read of the same fine-tunes.
Found
  • The reuse member reads above its twin in 8 of 8 counted pair-seeds, as filed, but only by 0.00004 to 0.0028 on readings of 0.996 or more.
  • The gaps rank the pairs as the twins' larger MLP updates do; the equal-update memorised-fact pair ties.
