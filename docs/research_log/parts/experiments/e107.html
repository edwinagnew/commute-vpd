If the answers are made wrong but everything else is kept, do the carrying neurons stay where they were?

2026-11-06 · provisional, independent check holds with caveat · one cluster debug job (53575), $0 · experiments/label_vs_style

The question. E103 and E105 found that which neurons carry an update (its carrying set) separates fine-tuning on facts Qwen3-1.7B already knows from fine-tuning on invented authors, and that swapping the rows within the known facts barely moves the set. Answer style and topic (real people against invented authors) still differ between the two arms. Is the separation about whether the model already holds the fact, or about style and topic?

What we did. We trained on the known arm's exact 217 real rows, in the same five wordings, with every true answer replaced by a wrong one from the TOFU data (two seeds), so only whether the stated answer agrees with what the model holds changes. Beside it, a topic split of the known rows (real-author rows against world-fact rows). Each run is read at the step where its update's size matches the template fine-tune's, with controls first.

What we found. The wrong-answer run shares 84 to 88 percent of its carrying neurons with the true-answer run and sits no closer to the fictional run than the true-answer run does. Splitting the true rows by source moved the set more than making every answer wrong did (0.73 to 0.74 shared, on the scored invented-author reading). Both filed leans were wrong in direction.

What it means. At matched size the carrying set reads the data's source and style, not whether the trained answer agrees with what the model already says. The test had little power: the wrong answers moved the update about as much as a new seed does, and little fact content had been learned. Genuinely new facts and a larger update size are untested, and the topic split is confounded with sentence length.

Cluster job 53575, one L40 on debug, $0: control, six arms, the sets and the score.
Found
  • Wrong answers about the same real people in the same style leave the carrying set where the true answers put it.
  • The independent check re-derived every overlap and verdict; the wrong arm did train wrong answers, but the label moved the update only about as much as a seed.
  • No neuron reading tried separates known from new at matched size; this is scoped to contradicted facts.
Bears on
The comparator line (baseline-lead): the neuron signal of reuse against new knowledge does not survive the style and topic control at matched size.
