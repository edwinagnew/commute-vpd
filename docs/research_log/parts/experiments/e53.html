Does the original 67M model already perform lowercase text and fail a word cipher, so the two can serve as an "existing" and a "new" fine-tune on the same rows?

2026-10-29 · RunPod 4090, $0.08 · experiments/performed_anchor

The question. The re-gating line's only number that has told an existing behaviour's fine-tune from a new one's is the stand-in ratio, and it has been read only on toys the original model does not perform at all (E46, E50). The user chose (2026-10-29) to test it on a pair the original model really performs: continuing lowercase Pile text in lowercase, against a fixed swap of 50 common words, both fine-tuned on the same rows. The check that this pair is what we say it is comes first, before any fine-tune. This card is that check, stage A0.

What we did. We ran the original model only, on 256 Pile rows, and measured three log-odds in nats. For lowercase, at 6,070 positions where the next word was capitalised in the original text and both forms are one token, how much more likely the lowercase form is than the capitalised one, in rows lowercased first. The same positions in the unchanged rows should read the opposite way. For the cipher, at 2,916 positions where the next word is one of the 50 swapped words, how much more likely the swapped word is than the real one. Filed thresholds: lowercase at least +1, capitals in cased text at most -1, cipher at most -3. A control reproduced the model's earlier reading of these lowercased rows, -3.146 nats a token, within 0.01. The plan stops if the control misses, lowercase is not above 0, or the cipher is above -1.

What we found. The original model passed all three: it prefers the lowercase form in lowercased text by 1.18 nats (90% range 0.84 to 1.56), prefers capitals in cased text by 5.58, and cannot do the cipher, which reads -5.53, so it strongly prefers the real word. The control read -3.14576. The decision is go.

What it means. The original model performs lowercase continuation without being told, and does not perform the cipher, so the pair is a fair anchor for the first time: an "existing" member it does, a "new" member it cannot. The lowercase preference is modest, 1.18 against 5.58 for capitals, and only 65% of positions lean the right way, so it is a weak performer. The fine-tunes themselves wait on three open questions in the plan; nothing about the stand-in ratio is known yet.
