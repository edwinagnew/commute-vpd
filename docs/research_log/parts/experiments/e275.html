Do claim 2's comparisons change when the write share is taken over the needed set instead of the mean-ablation circuit?

2026-11-23 · cell P2.62, compare-lead, descriptive, red team: holds with caveats · experiments/claim2_needed

The question. The paper's second claim says cheap readings track the write share. Those comparisons were run with the write share taken over the circuit found by mean ablation. The definition instead asks about the needed set: the variables whose swap between two inputs changes the fine-tune's top token. Does any number in the results picture change when the share is taken over that set?

What we did. We reran each comparison through the code that first computed it, changing only the set under the write share. Three tables: nine built pairs (a task built to reuse a skill against one built to need a new one, 76 states), twenty prior-matched seeds (ten of key copy, ten of a cipher the base model finds about as likely) and 56 procedural states (38 fine-tunes and 18 random updates). Each reading's agreement with the write share was compared with a sampling floor, set before any pod ran. No bar was filed; the card named two rivals (nothing moves by 0.2, or something does).

What we found. On the built pairs every reading agrees with the write share on the same pairs and with the same rank correlation over either set, and no pair gap changes sign. On the prior-matched pair the write share over the needed set puts all ten copy seeds above all ten cipher seeds, and the cheap readings correlate with it at 0.66 to 0.83. On the procedural states steering's correlation given output change rises from 0.07 to 0.46 and effective rank's weakens, but both moves come from the 16 states whose needed set holds under 1,000 variables: on the 23 well-sampled states neither moves (steering -0.484 to -0.483). One reading does move there: the untrained decomposition's correlation given output change strengthens from 0.30 to 0.65.

What it means. Claim 2 keeps its numbers: the comparisons are unchanged over the needed set on the built pairs and on the prior-matched pair, and the procedural steering move came from under-sampled states, so it is not an effect of the needed set. Red-team's verdict was "holds with caveats": the procedural floor is nested (128 pairs against 256 that include them), and the well-sampled subsets hold twelve states each. The premise check is doubtful, since the needed set was never validated against a known answer.

Run
Scans on pods ($9.56 in all); the comparisons themselves are CPU, $0; one run of four allowed.
Found
  • Built pairs and the prior-matched pair read the same over the needed set, as one rival expected.
  • Procedural steering and effective rank moves come from 16 states with needed sets under 1,000 variables and vanish on the 23 well-sampled states.
  • The untrained decomposition's procedural correlation strengthens (0.30 to 0.65 given output change), the one number that changes; its floor is nested, so it is provisional.
