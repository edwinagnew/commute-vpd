## The comparison rule (`qc.separates`, already filed in E92)
A number counts if |mean anchor 1 − mean anchor 2| is strictly over the larger of the two same-anchor seed spreads. Own rows whole-question decides rows 1 and 4; maths rows decide 3 and 5; maths row 1 is printed, and a disagreement reads "depends on the rows". Row 2 needs no row set. Beside it, not changing it, every counted number prints: its row half-width, and at the full update whether **the same rule also counts between the two random sizes** ("size can do this"). No-call or missing seed: "unread".

| case | outcome |
|---|---|
| Gap equal to spread | Does not count (strict) |
| Spread exactly 0 | Any gap counts, so the half-width printed beside decides how it is worded |
| Do-nothing on both anchors, row 1 | 0, 0: does not count. Good |
| Do-nothing, raw kept | **Could pass** without any placement: so row 4 is credit, and raw kept is not scored |
| Do-nothing, rows 2, 5 | Same as the state: can pass. They describe δW and Γ, never the map; say so |
| W0 as both anchors | No call on every number: "unread" |
| Zero denominator, gain under 0.05 (E72's bar) | "unread" |
| Empty set, under 2 rows in a class | "unread" |
| Matched-step gap | May count; reads "cannot come from facts the update recalls" (E91) |

**Stop rule (amendment, unchanged).** If no number counts at the full update or the matched step, that is D3's finding, reported so, and the GSM8K arms are read as description. Past-line states do not enter it.
