# P2.38 run 2 (E211): every method on the real-text pairs, size-matched

Cell P2.38 run 2 of 3 (due 2026-11-22). Card `reports/plans/2026-11-18_plan_p2-38-run2-card.md`; run 1's reading
`reports/analyses/2026-11-18_analysis_realistic-tasks-run1.md` (E209); design draft
`reports/plans/2026-11-18_plan_realistic-tasks-draft.md`. Rules, expected values and settings:
`experiments/realistic_tasks/results/predictions_run2.json`. Code: `experiments/realistic_tasks/run2.py` (jobs),
`src/commute/realistic_reads.py` (the readings, each an existing shared step), `src/commute/realistic.py` (read
positions, size, the scorecard's call; tests `tests/test_realistic.py`), `experiments/realistic_tasks/score2.py` (CPU).

**What runs.** Three pairs, the reuse side first, as run 1 kept them: topic label vs coin label (L1/L3), French vs
Yoruba (T2/T3), lowercase vs reversed word order (T1/T4). Each task is fine-tuned at Adam 3e-5 (run 1's rate), three
seeds, and its update saved at the first step it reaches each of two sizes. Every method then reads every saved update:
the share, the share on W0's SVD (and its rotation), pooled steering, TopK neurons (k 64 and k matched), k_half, the
original model's prior, erank and size. Controls in every task: a zero update first (every numerator exactly 0, else
stop), then three Gaussian updates per size with seed 0's per-matrix norms (stop if one gains 1 log-odds).

**Choices settled in the weeds** (Fable, 2026-11-18; the lead's decisions.md row of 2026-11-18 on the contrast stands):
- Sizes: label pair 0.010 and 0.005 (L1 reaches only 0.0103 by step 300; 0.018 would need ~3,000+ steps, a different
  regime); LM pairs 0.0175 and 0.00875 (T1 ends E53's 2,400 rows at 0.01795, so T1 stays E53's run). Each pair is
  matched within itself, not across pairs. A seed that misses its size by its cap (600 label steps, 300 LM steps) is
  read at the cap and listed.
- Label rows: both sides on the 512 training texts (the coin is defined only there), the contrast scored, whole-vocabulary
  log-odds beside; held-out gain beside (the coin's contrast should read near 0, L1's over 1).
- LM rows: in each held row the 8 word starts of lowest W0 log-odds, the 500 lowest of those (W0 only, fixed before
  training); T1 keeps E53's 500 windows. Run 1's mean word-start gain for French (0.30 at 0.022) is under the share's
  floor of 1, so French may still read nan: reported as read.
- Call: the scorecard's own rule (seed ranges do not overlap), unchanged, so these cells sit beside the nine built
  pairs'. It calls "apart" by chance 0.1 of the time per cell; a method is read on its direction across the pairs.

**Expected values** (full list in the predictions file). Zero: every numerator 0 exactly. Gaussian: gain under 1,
shares nan, erank 650-760, above every trained state's. Control job: E53 lowercase_s0 and cipher_s0 reproduce share
0.752/0.124, untrained 0.118/0.068, gain 1.672/3.868, neurons, pooled steering 0.713/0.693, erank 598.6/594.3 and
k_half 16. T1's share at 0.0175: 0.72-0.78. L3's held-out contrast gain within 0.3 of 0.

**Predictions** (direction in each method's gap convention; + = reuse side higher, for k_half fewer neurons):
share none on L1/L3 (low; E140's twins), + on T2/T3 (low), + on T1/T4 (medium, gap 0.25-0.45); untrained and steering
none everywhere (low); neurons none on L1/L3 (medium, inert), + on both LM pairs (low); k_half none on L1/L3, + on the
LM pairs (low); prior + on all three (high, medium for T2/T3); erank - on L1/L3 (low), + on the LM pairs (low); size
matched, |log10 gap| at most 0.005. Card: rival a if the share reads apart upward on both LM pairs at both sizes and the
label gap is not negative; rival b if at the larger size two pairs read no call or reversed.

**Platform, time, cost.** MATS cluster `debug` QoS, L40, $0; one script `cluster/realistic_tasks_r2_job.sbatch <job>`.
The control job runs first and alone; the six task jobs wait on it (`afterok`) and run in parallel (8 L40s, 1 GPU per
debug job). Times from run 1's log (61424: model load 75 s, a full E53 read about 60 s) and E172's (k_half 17 s on E53
lowercase): ctl ~6 min; each LM task ~21 min (13 reads of 500 windows of 127 tokens at ~85 s, three 300-step fine-tunes
at 18 s); each label task ~6 min (512 windows of 33 tokens, two units). Wall time ~30 min if the six start together;
GPU time ~100 min. Then `score2.py` on the CPU worker, seconds. Not gated ($0, under 6 h): no review before it runs.
Saved: each update in bf16 under `results/large/run2/` (~57 MB, 36 files, ~2 GB) for run 3's crosscoder.

**Blind spots.** The share reads where the gain passes through the decomposition's gates, not whether the base model's
mechanism is reused; the hard-position rule makes every LM prior a bottom tail and adds regression toward the mean to
every gain; the prior is circular on LM tasks (W0's loss is the data argument); size is matched by design and reads
nothing.

**Not run.** The crosscoder (run 3); Qwen; sizes across pairs equal (each pair matched within itself); FLORES+
parallel sentences (gated); the L2 sentiment task (dropped by run 1).
