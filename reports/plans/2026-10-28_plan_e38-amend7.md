## The request, in the Terms' words

Amendment 6 put back the switched-on set S and the direction-matched set D together and found the two take back about
the sum of their parts ("separate"). Its check showed that restores of disjoint sets add almost linearly on these
states, so any two disjoint sets of target-pointing subcomponents might read the same, and "separate" would say nothing
about S. Two questions settle it: do D and the next-ranked target-pointing set D₂ also read "separate"; and does the
top-ranked target-pointing set of twice S's count per matrix, S's members allowed (T₂), take back as much as S and D
together?

## Definitions

- ρ(X), e_c (training windows), S, D: as Amendments 5 and 6; sets read from `amend5.json`'s members, e_c from
  `results/large/amend5_scores.pt`. n_k = |S ∩ k| per matrix k.
- **D₂**: per matrix, the n_k alive subcomponents outside S ∪ D with the largest training e_c (ties: index), that is,
  ranks n_k + 1 to 2n_k of D's own ranking. Short if fewer exist.
- **T₂**: per matrix, the 2n_k alive subcomponents with the largest training e_c, S's members allowed (ties: index).
  Short if fewer exist. Reported: how many of S's members T₂ holds.
- a₂ = ρ(D ∪ D₂) − max(ρ(D), ρ(D₂)), as Amendment 6's a.

## Decision tree

**P15** (is "separate" generic?). Per seed: "unscored" if G < 1, D₂ is short in any matrix, ρ(D) < 0.10 or ρ(D₂) <
0.10; else Amendment 6's rule on a₂ ("separate" if a₂ ≥ 0.5 × min(ρ(D), ρ(D₂)), checked first; "redundant" if a₂ ≤
0.05; else "partial"). Task: an unscored seed makes it unscored; else the seeds' common class, else "seeds disagree".
Reading over the scored tasks: "generic" if there is at least one and every one is "separate"; "not generic" if there
is at least one and every one is "redundant"; "unscored" if none; else "outside the tree". (On ` which` D₂'s
first-order share is about 0.09, so ` which` may be unscored; emoticon is the expected read.)

**P16** (does one target-aware ranking at the same count carry what S ∪ D does?). Per seed (G ≥ 1, T₂ not short):
"covers" if ρ(T₂) ≥ ρ(S ∪ D) (ties covers); "short" if ρ(T₂) < ρ(S ∪ D) − 0.05; else "unclear". Task: the seeds'
common class, else "seeds disagree"; an unscored seed makes it unscored. Read on emoticon and ` which`; reading
"covers" if both are "covers", "short" if both are "short", else "outside the tree".

**Together.**
- **P15 "generic" and P16 "covers"**: Amendment 6's "separate" says nothing about S, and a ranking toward the target
  at the same count takes back as much as S and D together. Card reading: on this model S's share is what
  target-pointing subcomponents carry; Γ finds a set enriched for them without the target, and no more. The card
  leans to option (a), close the 67M restore line.
- **P16 "short"** (either P15): S ∪ D carries something the best target-aware set of its size misses. Card leans to
  (b) the upstream step or (c) the Qwen line.
- **Anything else**: card with the numbers; the user picks.

## What each number is blind to

- T₂ is the best set to first order, not the best set; it can lose to S ∪ D through interactions alone, which would
  read "short" without S being special. ê(T₂) is reported beside ρ(T₂) to show this.
- D₂ is weaker than D by construction; the floors keep the rule off small shares.

## Noise floors

0.05, as Amendments 4-6: Amendment 3's random sets never exceeded 0.029; S's seeds differ by at most 0.023.

## Edge cases checked before filing

D₂ or T₂ short: that seed unscored for its rule. ρ(D₂) < 0.10: unscored (the expected case on ` which`). No scored
task in P15: "unscored", no branch. a₂ < 0: "redundant". The P14 tie order carries over ("separate" first). ρ(T₂) ==
ρ(S ∪ D): "covers". G < 1: nan, caught first. S ⊂ T₂ entirely: allowed; T₂ is then S ∪ (top n_k outside S) = S ∪ D
exactly, and P16 reads "covers" by the tie rule (reported).

## Not run

Rankings beyond first order; D₃ and further; positions other than the trigger; the upstream step; the larger model.
