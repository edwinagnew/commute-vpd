# P2.38 run 1 (E209): realistic tasks on the 67M, the premise run

Cell P2.38 (3 runs, due 2026-11-22). Card `reports/plans/2026-11-18_plan_p2-38-run1-card.md`; design draft
`reports/plans/2026-11-18_plan_realistic-tasks-draft.md`, whose task list this follows. Lead's overrides of the draft:
67M only; training to size (0.018 and half) is run 2's, not run 1's; FLORES+ is gated on HuggingFace, so each language's
scored rows are held-out Wikipedia articles (training rows from the dump's first articles, 64 held-out rows from the
articles after them, since the small wikis open with alphabet and meta pages). Run 1
reads no share: it decides which real-text tasks go to run 2, and at what rate.

**What runs.** One debug-QoS L40 job, $0, about 20 min (`cluster/realistic_tasks_r1.sbatch`, `sbatch --comment=E209`).
Code: `experiments/realistic_tasks/run.py`, data and rules `src/commute/realistic.py` (tests `tests/test_realistic.py`).
Reused unchanged: holes_fill's `Job` (E143's gain, TopK neurons, fair steering), `local_faith.route_split` (E136's share),
`lowercase.task` (T1's rows), `finetune.finetune_arm_a` / `finetune_arm_b`, `label_reads.labelled`,
`case_label.value_probes`, `definition_reads` reads.

| task | data | side, by its data argument |
|---|---|---|
| L1 | AG News Sports vs Business, 32 text tokens + " Topic:", label " Sports"/" Business" | reuse |
| L2 | SST-2, same format, " positive"/" negative" | reuse, weaker |
| L3 | L1's texts, label a seeded coin per text | new by construction |
| T1 | E53's lowercase rows | reuse (E53) |
| T2 | French Wikipedia | reuse (EuroParl in the Pile) |
| T3 | Swahili, Tagalog or Yoruba Wikipedia, the highest W0 nats per byte | new |
| T4 | Pile rows, each sentence's words reversed | new |

Label tasks train on a pool of 512 texts (256 a class), so L3's coins can be memorised (about 19 visits each); L1/L2 gains
are read on 512 held-out windows, L3's on the pool (a coin has no held-out reading; its held-out gain is reported as a
check, expected near 0). LM tasks use E53's arm-B recipe: 2,400 rows of 512, batch 8, each row once, 64 held-out rows.

**Stages and expected values.**
- Stage 0, alone, stop on a miss. E53 lowercase_s0 / cipher_s0 through the scorecard's readers: share 0.7519 / 0.1243
  (tol 0.01), gain 1.6721 / 3.8681 (1e-4), neurons k64 0.0341 / 0.0049 and k matched 0.0078 / 0.0010 (1e-4), pooled
  steering 0.7131 / 0.6930 (1e-3). Zero update: exactly 0 on the neuron reader and the LM read. T1's W0 logp -3.14562 (1e-4).
- Stage 1, W0 premises (filed rule `realistic.premise_calls`): L1 best-block probe >= 0.9 (expected 0.93-0.98), L3 <= 0.6
  (0.45-0.56), L2 >= 0.7 (0.72-0.85); T3 = the highest nats per byte of sw/tl/yo, kept if >= 1.2 x French (French
  0.9-1.3, T3 1.4-2.2); T4 reversed minus in-order >= 1 nat per token (3.0-3.5 vs 5-6.5). A failed member drops its pair
  (L1/L3, T2/T3); T4's failure drops T4 only, T1 is the bridge and stays; L2 stands alone. Reported: W0 zero-shot label
  accuracy and bias, probe per block.
- Stage 2, rates 3e-5, 1e-4, 3e-4 x 300 steps, seed 0, checkpoints 10/30/100/300. T1 at 3e-5 runs first and alone: it is
  E53's recipe, gain 0.12963 within 0.003, else stop. Filed rule `realistic.grid_calls`: a task is kept when its largest
  gain at a checkpoint of size <= 0.021 reaches 1 log-odds (label tasks; the share's MIN_GAIN) or 0.05 nats per token
  (LM tasks; 40% of E53 lowercase's 0.130 at size 0.018). Expected: T1 0.13 at 0.018; L1 2-5; L2 1-3; T2 0.1-0.3; T3
  0.2-0.5; T4 0.3-1.0; L3 uncertain (the likeliest drop). Size about linear in rate: 3e-4 passes 0.021 by step 30.
  Reported: each LM task's log-odds gain at word-start positions (run 2's share needs 1 there; T2 likely under), the
  rate run 2 would use (largest gain under the cap, ties to the lower rate).

**Data dry run** (CPU worker, no model, 2026-11-18): every loader ran on the real data in 43 s, downloads included.
AG News 60,000 / 3,800 Sports+Business texts; SST-2 36,775 train and 838 validation sentences of 8 tokens or more
(mean 9.6 pad tokens of 32); 2,400 + 64 rows for each of fr, sw, tl, yo (bytes per token 3.34, 2.48, 2.73, 1.95);
T4's rows read as reversed sentences. Label words are single tokens.

**What each number is blind to.** The probe sees linear readability at one position, not use; the coin control is its
floor. Nats per byte across languages compares different articles, not parallel sentences (FLORES+ would have been
parallel). The gain bar says a task can be learned at the built pairs' sizes, not how.

**Cost and time.** $0 (debug). Model load ~2 min, stage 0 ~3 (E143 read 56 states in about 10 min; two E53 share reads,
~20 GB host), stage 1 ~5 with downloads (dry run on the CPU worker below), stage 2 ~8 (LM runs ~18 s per 300 steps,
E53's log on L40; 12 of them; 9 label runs of 35-token windows). Stage 2 stops itself if projected past 15 min.
--mem 40G as share_untrained.sbatch; --time 30 min.

**Gates.** Not a gated run ($0, under 6 h): no review before it runs (fast lane).

**Not run.** The share or any baseline on the new tasks; seeds 1-2; size-matched states; Qwen; FLORES+ parallel scoring.
