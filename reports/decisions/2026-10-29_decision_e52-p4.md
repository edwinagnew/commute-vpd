# Decision pending: E52's prompting check (P4) came out reversed (2026-10-29, ask #2)

**Observation.** Prompting the original model with 16 worked examples recovers 0.11 of the copy fine-tunes' gain
and 0.14 of the cipher fine-tunes' gain (E52, job 44095). The filed P4 predicted copy higher. The plan's tree says:
P4 fails, so stop and ask. Steering separates the two kinds strongly (P3: 0.77 copy vs 0.14 cipher).

## Fable's advice (advice only; the user decides)
- **Both prompting numbers are near zero.** After 16 examples the target's probability is still about 1e-4. The
  "reversal" is a 0.03 gap between two near-null shares. The filed rule had no minimum effect, so a null pair could
  still "separate". The cipher's slightly larger gain fits a shift in the prior toward the value pool's tokens, not
  task performance. The cipher cannot be done in context by design, because its values never appear as keys.
- **The labels were never checked by behaviour.** E12 called the copy task "existing" because the model has copying
  machinery, a claim about mechanism. Immediate repetition after a marker is something language models suppress
  (W₀ gives the target 4.5e-5). So P4 does not show the labels are wrong; it shows they were never verified.
- **The prompt format is weak.** The examples sit before 19 tokens of unrelated Pile text, not next to the query,
  with no separator. A 4-layer model may lose most of any in-context effect that way. The indexing is correct.
- **P3 may be tautological on this set.** One mean vector cannot depend on the input. The copy change is one mode
  switch, and the cipher change depends on the key. So steering separates these two kinds whether or not the
  difference is teach vs elicit. VPD's route split may be reading the same property. The case that would tell them
  apart is a key-dependent map the original model already performs weakly, which fine-tuning then strengthens.
- **Options.**
  - A. Amend P4 (dated) and rerun prompting only: examples next to the query, n = 4, 16, 31, top-1 accuracy, and a
    minimum effect (copy share at least 0.5). One debug job, $0.
  - B. Write up P3 with the caveat above. $0, but it builds on unverified labels.
  - C. Build the key-dependent "elicit" pair (needs `/design`), fine-tune it with E12's recipe, and run steering and
    the route split on it. $0, one or two debug jobs.
  - Fable recommends A, then C. If A gives a copy share of at least 0.5, the labels hold and the tree's "baseline
    separates" branch applies; C is still what makes the comparison informative.

## Lead's recommendation
