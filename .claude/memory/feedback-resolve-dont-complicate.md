On 2026-10-14 the user asked to make the thresholds lead testable. My first reply listed sources of demand, four
synthetic tests, three real-model tests and a design check. The user: "too much information there with no real sense
you've resolved my question other than adding more complications"; "still basically saying a feature is neuron
aligned if it needs to be fed through a relu. If you are saying more than that, make it clearer"; "responses need to
be much more concise without so much waffle". The second reply (one-sentence claim, the null, three predictions the
null does not make, one falsifier) was accepted.

**Why:** the user wants to know whether a framing has content before seeing the apparatus around it; detail belongs in
the report file, not the chat.

**How to apply:** for theory or framing questions, lead with the claim in one sentence, the competing null, and the
two or three predictions that separate them. Put the rest in `reports/`. Related: [[feedback-concise-design-check]],
[[feedback-plain-language-and-name-the-plot]].
