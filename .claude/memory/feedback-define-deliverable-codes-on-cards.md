Never use a deliverable code (D1, D2, D3) on a decision card or in chat without its plain meaning or a link to where it is defined.

**Why:** the user read the D1 card and could not tell what D1 meant or whether a decision was still wanted (2026-11-03); they read the log and chat only.

**How to apply:** one plain sentence beside the code, every card. Also say which old methods an option keeps or drops, since the user asks why not simply use them. See [[feedback-decision-cards-cold-reader]], [[feedback-user-reads-log-and-chat-only]].

Same for run short names in chat: the user asked "what is u1??" and "what is the small-fraction about?" (2026-11-04). Say "u1, the first Qwen fine-tune, on GSM8K, stopped at step 10" the first time in a message, and restate a pending question in full rather than by a label.
