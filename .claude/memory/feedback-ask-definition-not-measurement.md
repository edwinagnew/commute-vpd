When the user says "if a case is not settled, stop and ask me", ask only what changes the definition (level, pairing, distance, what counts as the reading). A detail of how a reading is computed (e.g. whether a zeroed unit stays zeroed while searching sufficient sets) is the lead's call: decide, state it in the plan.

**Why:** 2026-11-17 P1.25 dialog: user replied "i dont understand why you are asking this. this sounds like a cheap measurement, rather than a question about the definition", and first asked what retention/contrast/"the set" even meant — jargon in a dialog lost them.

**How to apply:** before a dialog, sort each open case into definition vs measurement; ask only the first kind, in plain words with no coined terms. Related: [[feedback-fable-for-weeds-details]], [[feedback-plain-approval-requests]].
