**Superseded 2026-11-09** by `reports/plans/2026-11-09_plan_paper-roadmap.md`: asks stay short, but direction comes from the user and the table of work, never from Fable; no other model gives a go-ahead.

Leads are meant to be particularly autonomous: keep messages to the user very short, consult Fable for high-level direction, and don't assume the user has read a plan (user, 2026-11-05: "too much information... i havent read the plan").

**Why:** a design check and plan restated in chat was more than the user wanted, even though their task said to show it.

**How to apply:** at most a few lines and one plain question, only when it is truly the user's call. See [[feedback-fable-first-fewer-questions]], [[feedback-short-chat-replies]].
