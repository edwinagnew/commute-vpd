When submitting a proposal for the user's approval, lead with three plain sentences: (1) the observation it builds
on and why it looks promising, (2) the technique as one operation with every symbol and step explained (e.g. where a
"clip" comes from), (3) the exact yes/no being asked. Only then the readings and the design check.

**Why:** 2026-10-22 the Item D design check (Γ's values shifted by one fixed change) was put to the user as a list of
readings and five confirmations; the user said "its very unclear what you are asking or how legitimate it is ... I
really wish you were clearer when you submitted things to my approval so it was easier for me to assess."

**How to apply:** the chat message that asks for approval is a summary a reader with no context can assess; the
plan file carries the detail. Related: [[feedback-concise-design-check]], [[feedback-short-chat-replies]],
[[feedback-user-definitions-override-files]].
